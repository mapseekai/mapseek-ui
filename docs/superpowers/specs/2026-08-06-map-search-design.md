# 地图搜索业务组件设计

## 目标

提供一个可直接放置在地图界面上的组合搜索组件，支持地名搜索与经纬度搜索。组件负责完整的输入、候选、校验、加载、错误、清除和收起交互，但不绑定地理编码服务或地图 SDK；数据检索与地图飞行通过回调注入。

## 范围

本次新增一个注册表业务组件及对应 Showcase。组件复用仓库已有的 Tabs、输入框、按钮、图标按钮和反馈样式，不引入新依赖。

组件不负责：

- 调用具体地理编码服务；
- 持有地图实例；
- 决定地图缩放级别、动画时长或投影转换；
- 保存搜索历史或提供多选能力。

## 组件结构

`MapSearch` 是唯一对外业务组件，内部包含以下区域：

1. 展开态容器：顶部为“地名搜索 / 经纬度搜索”Tabs，右侧为收起按钮。
2. 地名搜索面板：关键词输入、定位按钮、清除按钮，以及候选结果列表。
3. 经纬度搜索面板：经度和纬度输入、字段级错误提示、定位按钮和清除按钮。
4. 收起态入口：单个搜索图标按钮，点击后恢复展开态。

Tab、展开状态、输入值、搜索结果和异步状态由组件内部管理。收起和再次展开不会丢失当前 Tab、输入内容或候选结果。切换 Tab 也保留两个面板各自的输入状态。

## 公开 API

```ts
export type PlaceSearchResult = {
  id: string
  name: string
  description?: string
  longitude: number
  latitude: number
}

export type MapSearchProps = {
  onSearchPlace: (
    keyword: string,
    signal: AbortSignal,
  ) => Promise<PlaceSearchResult[]>
  onSelectPlace: (place: PlaceSearchResult) => void
  onLocatePlace: (keyword: string) => void | Promise<void>
  onLocateCoordinates: (coordinates: {
    longitude: number
    latitude: number
  }) => void
  defaultTab?: "place" | "coordinates"
  defaultCollapsed?: boolean
  searchDelay?: number
  className?: string
}
```

默认 Tab 为 `place`，默认展开，默认搜索防抖时间为 300ms。

## 地名搜索流程

关键词去除首尾空白后为空时，不调用 `onSearchPlace`，并清空候选和搜索错误。非空关键词经过防抖后调用 `onSearchPlace(keyword, signal)`。

每次新搜索会中止上一次请求。组件只接收当前未中止请求的返回结果，防止较慢的旧响应覆盖新响应。请求期间显示加载状态；成功且结果为空时显示无结果状态；非中止错误显示搜索失败状态。

点击候选项时，组件记录该候选为当前选择，并立即调用 `onSelectPlace(place)`。地图飞行由调用方完成。

点击输入框后的定位按钮时，组件使用当前标准化关键词调用 `onLocatePlace(keyword)`。该操作不依赖当前候选，也不替组件选择第一条结果。关键词为空时定位按钮禁用。异步回调执行期间按钮显示忙碌状态并防止重复触发；失败时显示非阻断错误。

清除操作会重置关键词、当前选择、候选结果和地名搜索错误，并中止尚未完成的搜索请求。

## 经纬度搜索流程

经度与纬度分别输入，允许小数与负数。输入值保持为文本，以便正确表达用户尚未完成的中间状态，例如 `-`、`.` 或空值；定位时再转换为数字。

输入一旦形成可解析数字便立即校验范围，因此越界值会直接显示错误；空值、非数字等未完成状态在字段失焦或尝试定位时显示错误：

- 经度必填，必须是有限数字，范围为 `[-180, 180]`；
- 纬度必填，必须是有限数字，范围为 `[-90, 90]`。

存在任意错误时禁止执行定位。校验失败通过字段旁文本、`aria-invalid` 和错误描述关联呈现。通过校验后调用 `onLocateCoordinates({ longitude, latitude })`。

清除操作会重置两个输入值、触碰状态和错误提示。

## 可访问性与键盘交互

- Tabs、按钮和输入框使用已有基础组件的键盘行为与焦点样式。
- 所有纯图标按钮都有明确的中文 `aria-label` 和 Tooltip。
- 候选列表使用可键盘导航的列表/组合框语义；回车选择候选后触发 `onSelectPlace`。
- 加载、空结果和错误状态通过可感知的状态区域呈现，不以颜色作为唯一反馈。
- 收起后焦点落到展开按钮；展开后不强制抢占用户当前焦点。

## 视觉与响应式

组件沿用现有主题令牌、边框、阴影、圆角和间距，不引入独立视觉体系。展开态作为紧凑地图浮层，默认宽度适合常见侧栏或地图角落；调用方可通过 `className` 调整布局。经纬度输入在可用宽度足够时并排，窄容器下自然堆叠。收起态只保留一个方形图标按钮。

## Showcase

Showcase 使用本地静态地名数据模拟异步检索，并展示：

- 输入关键词后出现候选；
- 点击候选与关键词定位分别更新可见状态；
- 地名搜索加载、空结果和失败状态；
- 合法经纬度定位；
- 经度和纬度越界错误；
- 清除、Tab 切换、收起与恢复。

## 测试与验收

至少覆盖以下行为：

1. 默认展示地名 Tab，可切换并保留各 Tab 状态。
2. 收起后仅显示展开按钮，再次展开恢复原状态。
3. 空关键词不搜索；输入防抖后调用回调。
4. 新请求会中止旧请求，旧响应不会覆盖新结果。
5. 点击候选调用 `onSelectPlace`，且参数完整。
6. 点击地名定位调用 `onLocatePlace`，不隐式选择候选。
7. 地名清除会重置输入、候选、选择和错误。
8. 经纬度空值、非数字和越界值均显示对应错误且不定位。
9. 边界值 `-180/180` 与 `-90/90` 可正常定位。
10. 经纬度清除重置输入和错误。
11. 纯图标控件、错误描述和忙碌状态具有正确的可访问语义。

完成后运行仓库既有格式化、类型检查、单元测试、注册表校验和构建检查；如存在与本次无关的既有失败，在交付报告中明确区分。
