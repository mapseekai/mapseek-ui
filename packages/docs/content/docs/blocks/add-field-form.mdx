AddFieldForm 是受控的“新增属性字段”表单主体。它只处理字段名、字段类型、与类型匹配的默认值、nullable 和说明输入；弹窗、底栏提交、schema 写入和校验策略由调用方负责。

import {

## 用法

从 `EMPTY_ADD_FIELD` 初始化 `value`，把 `fieldTypes` 作为业务允许的类型列表传入，并在 `onChange` 中保存完整草稿。支持的类型是 `text`、`integer`、`float`、`boolean` 和 `date`；默认值会分别使用文本、数字（浮点型步长为 `0.1`）、“是 / 否”选择，或默认显示当天的 Calendar 日期选择器。提交按钮通常放在外层 Dialog 或 Drawer 中，并根据调用方规则检查 `value.name` 和重复字段名。

## 公开导出与 Props

导出 `AddFieldForm`、`EMPTY_ADD_FIELD`、`AddFieldDefaultValue`、`AddFieldType`、`AddFieldFormProps`、`AddFieldFormLabels`、`AddFieldValue` 和 `FieldTypeOption`。关键 props 是 `value`、`onChange`、`fieldTypes`、`labels` 和 `className`；`FieldTypeOption` 为每个受支持类型提供标签和图标。

## 状态与校验

组件本身不提交、不弹错、不去重；它保持所有字段输入可编辑，并把每次变化同步给调用方。示例中的“可提交 / 字段名必填”状态展示了外层如何把草稿转换为提交可用性。

## 无障碍

字段使用可读标签和输入控件。类型按钮是 `button`，日期选择器由可聚焦触发按钮与 Calendar 组成，nullable 使用复选框与 `label` 绑定。外层提交区应提供明确的错误文本，并把 Dialog 标题、说明和提交按钮状态暴露给键盘与读屏用户。
