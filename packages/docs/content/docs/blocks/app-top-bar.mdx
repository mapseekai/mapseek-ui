AppTopBar 是地图编辑器的应用顶栏。它负责返回按钮、品牌槽、工程名、保存按钮和动作插槽的布局；品牌、保存状态、快照动作、路由和持久化逻辑由调用方提供。

```tsx
  type AppTopBarLabels,
  type AppTopBarProps,
  type AppTopBarSize,

```

## 用法

把 `projectName`、`brand`、`status` 和 `labels` 作为展示输入传给组件，并把 `onBack`、`onSave` 接到应用路由与保存流程。`beforeSaveActions`、`afterSaveActions`、`centerActions` 和 `endActions` 用于放置调用方自己的导出、历史、快照或共享按钮。

传入 `centerActions` 时，桌面端通过左右等宽列与中间列保持工具组几何居中；在 `md` 至 `lg` 之前，品牌与状态会暂时隐藏，工程名收缩省略，以避免遮挡中间工具组。

## 尺寸

`size` 提供 `xs`、`sm`、`default` 和 `lg`，默认值为 `default`。桌面端始终保留上下各 4px 的外层留白：

| `size` | 内置 Button | 内部工具栏 | 外层顶栏 |
| --- | ---: | ---: | ---: |
| `xs` | 24px | 24px | 32px |
| `sm` | 28px | 28px | 36px |
| `default` | 32px | 40px | 48px |
| `lg` | 36px | 48px | 56px |

该 prop 会同步调整内置返回与保存按钮到对应的 Button 尺寸。动作插槽、`brand` 与 `status` 由调用方提供；动作 Button 也应使用同一尺寸档位。

## 公开导出与 Props

导出 `AppTopBar`、`AppTopBarProps`、`AppTopBarLabels` 和 `AppTopBarSize`。关键 props 是 `size`、`projectName`、`labels`、`onBack`、`onSave`、`saveDisabled`、`savePending`、`brand`、`status` 和四个动作插槽。组件不内置品牌资源或状态 Tag 样式。

## 受控状态

保存状态由调用方拥有。示例中点“保存”会清除 dirty，点“另存为”重新标脏，点“快照”只更新外层状态文本。真实应用通常会把 `savePending` 绑定到异步保存 promise，并在失败时由外层 toast 或 Dialog 呈现错误。

## 无障碍

返回按钮使用 `labels.back` 作为可访问名称，保存按钮使用 `labels.save`。传入动作插槽时优先使用原生 `button` 或项目 Button，并为图标按钮提供 `aria-label` 或清晰文本。`status` 文案应包含可读状态，不要只依赖颜色。
