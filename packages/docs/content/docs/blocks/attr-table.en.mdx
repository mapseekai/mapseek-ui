AttrTable provides the public pieces for attribute tables: schema table, virtualized data table, bottom sheet shell, static row source, and attribute-column helpers. Data loading, errors, selection, and sheet visibility are caller-controlled.

## Usage

`SchemaTable` reads field names and types and filters geometry/geography columns. `DataTable` consumes a `RowSource` plus `getRowKey`, `renderCell`, and `onRowClick`; use optional `getCellText` to expose the complete text of custom cell content. `AttrTableSheet` is a bottom-anchored resizable shell for map overlays.

## Public Exports and Props

Exports include `AttrTableSheet`, `DataTable`, `SchemaTable`, `attributeColumns`, `isGeometryColumn`, `useStaticRowSource`, `useTableSheetState`, `ColumnDef`, `RowSource`, `DataTableProps`, `SchemaTableProps`, `AttrTableSheetProps`, and `TableSheetState`. Key props are columns, row source, row key, cell renderer, full cell text for long content, selected key, empty label, retry label, and sheet header slots.

## States, Empty, and Error

`RowSource` expresses `items`, `totalCount`, `isInitialLoading`, `error`, and `refetch`. The demo toggles loading, error, and empty paths; row selection is controlled through `selectedRowKey`.

## Accessibility

Schema search is a native input, and copy/sheet buttons expose accessible names. The sheet resize handle supports Arrow keys, Home, and End. Provide a specific `ariaLabel` for every sheet instance.
