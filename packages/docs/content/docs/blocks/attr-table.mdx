AttrTable 提供属性表的公共构件：schema 表、虚拟化数据表、底部抽屉外壳、静态行源和属性列工具。数据加载、错误恢复、选择和抽屉开关由调用方控制。

## 安装

<RegistryInstall registryName="attr-table" />

## 导入

```tsx
import {
  AttrTableSheet,
  DataTable,
  SchemaTable,
  useStaticRowSource,
  type ColumnDef,
  type RowSource,
} from "@/registry/blocks/attr-table"
```

## 用法

`SchemaTable` 读取字段名和类型并自动过滤 geometry/geography 列。`DataTable` 读取 `RowSource`，通过 `getRowKey`、`renderCell` 和 `onRowClick` 接入业务数据；自定义单元格内容可通过可选的 `getCellText` 提供可发现的完整文本。`AttrTableSheet` 是贴底的可调整高度外壳，适合覆盖地图画布。

## 公开导出与 Props

导出 `AttrTableSheet`、`DataTable`、`SchemaTable`、`attributeColumns`、`isGeometryColumn`、`useStaticRowSource`、`useTableSheetState`、`ColumnDef`、`RowSource`、`DataTableProps`、`SchemaTableProps`、`AttrTableSheetProps` 和 `TableSheetState`。核心 props 是列定义、行源、行 key、单元格渲染、长内容的完整单元格文本、选中 key、空状态文案、错误重试文案和抽屉 header 插槽。

## 状态、空态与错误

`RowSource` 通过 `items`、`totalCount`、`isInitialLoading`、`error` 和 `refetch` 表达数据状态。示例中的开关覆盖加载、错误和空数据路径，行选择通过 `selectedRowKey` 受控。

## 无障碍

Schema 搜索使用原生输入，复制和抽屉按钮提供可访问名称。底部抽屉的 resize handle 支持键盘方向键、Home 和 End；调用方应给抽屉提供准确的 `ariaLabel`。
