BandStat displays min, max, mean, stddev, and a 64-bin histogram for one raster band, suited to raster detail, pixel diagnostics, and processing result views.

## Usage

Shape backend statistics as `BandStatData` and inject localized `BandStatLabels`. The demo shows the band switch while the caller owns the selected band and loading lifecycle.

## Public Exports and Props

Exports include `BandStat`, `BandStatData`, `BandStatLabels`, and `BandStatProps`. Key props are `data.band`, `data.histogram`, the four summary values, and axis / tooltip labels.

## Loading, Empty, Error, and Status

The block renders available data only; loading, empty, and error branches should be switched by the outer detail panel with LoadingScreen, Empty, or an error message.

## Accessibility

The histogram uses the Recharts accessibility layer. Keep numeric values paired with clear labels, and do not distinguish bands by color alone.
