<ShowcaseDemo registryName="custom-colormap" title="Colormap editing" description="Keep the committed value separate from the editing draft and only commit on Apply." minHeight={240} />

## Commit semantics

The caller owns `value`, `draft`, and `open`. Copy the committed value into the draft when opening, then commit the draft from `onApply` and close the dialog.
