FormInputs 是从样式编辑工作流中抽出的无领域输入控件集合，包括字符串、多行字符串、数字、复选框、选择、短枚举、自动补全、字体栈和数字范围输入。

## 用法

每个输入都接收当前值和 `onChange`，调用方保存最终值。`InputString` 和普通 `InputNumber` 采用编辑中本地状态并在 blur 或 Enter 后提交；`InputEnum` 会根据选项数量选择短枚举或下拉表达。

## 公开导出与 Props

导出 `InputString`、`InputNumber`、`InputCheckbox`、`InputSelect`、`InputEnum`、`InputMultiInput`、`InputAutocomplete`、`InputFont` 以及每个组件的 Props 类型。常用 props 是 `value`、`default`、`options`、`fonts`、`min`、`max`、`allowRange`、`rangeStep`、`required`、`disabled`、`aria-label` 和 `aria-labelledby`。`InputSelect` 的 `placeholder` 与 `InputAutocomplete` / `InputFont` 的 `emptyMessage` 由调用方注入，便于本地化。

## 状态与校验

数字输入会按 min/max 判断输入合法性；范围模式复用 `NumberRangeInput`。空字符串会转换为 `undefined` 或调用方指定的 fallback。示例中的重置按钮展示了空值、未选和空字体栈状态。

## 无障碍

用 `FieldGroup`、`Field` 和 `FieldLabel` 组织表单，并通过 `id` / `htmlFor` 关联可见标签；组合控件使用 `aria-labelledby`。短枚举和复选框保留可点击标签，下拉和自动补全继承基础 UI 的键盘行为。组件会把 `disabled`、`required` 和 `aria-invalid` 语义传递到实际控件，错误文案仍由外层 `FieldError` 提供。
