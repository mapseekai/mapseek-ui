GeoJSONView is a read-only GeoJSON viewer. The caller passes a pre-formatted JSON string; successful parses render a collapsible JSON tree, while empty values, parse failures, and unsupported primitives receive distinct, explicit states.

## Usage

Use `stringifyGeoJSON(data)` in the caller and pass the result to `json`. Pass `null` when nothing is selected, and localize the fallback with `emptyLabel`.

## Public Exports and Props

Exports include `GeoJSONView`, `stringifyGeoJSON`, `GeoJSONViewProps`, and `GeoJSONViewLabels`. Key props are `json`, `emptyLabel`, `title`, `expandAllLabel`, `collapseAllLabel`, `copyFeedbackDurationMs`, `labels`, and `className`. The `labels` object injects all visible expand, collapse, copy, copied, count, parse-error, and unsupported-value text.

## States, Empty, and Error

The component is display-only and stores no selected feature. `null` or an empty string shows the empty state; invalid JSON preserves the raw text and line numbers in an `alert`; a parsed primitive receives a separate warning state.

## Accessibility

The tree uses Base UI collapsible triggers for expanded state, content association, keyboard support, and the shared focus ring. Localize title, toolbar, count, and state text; never leave an empty selection as a blank panel.
