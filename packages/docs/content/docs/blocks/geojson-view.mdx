GeoJSONView 是只读 GeoJSON 查看器。调用方传入预格式化 JSON 字符串；组件解析成功时渲染可折叠 JSON 树，空值、解析失败或 primitive 会回退到带行号的 `<pre>`。

<RegistryInstall registryName="geojson-view" />

```tsx
import {
  GeoJSONView,
  stringifyGeoJSON,
  type GeoJSONViewLabels,
  type GeoJSONViewProps,
} from "@/registry/blocks/geojson-view"
```

## 用法

用 `stringifyGeoJSON(data)` 在调用方生成字符串，再把结果传入 `json`。没有选中要素时传 `null`，并用 `emptyLabel` 提供本地化空态。

## 公开导出与 Props

导出 `GeoJSONView`、`stringifyGeoJSON`、`GeoJSONViewProps` 和 `GeoJSONViewLabels`。关键 props 是 `json`、`emptyLabel`、`title`、`expandAllLabel`、`collapseAllLabel`、`copyFeedbackDurationMs`、`labels` 和 `className`。

## 状态、空态与错误

组件是纯展示，不保存选中要素。`json` 为 null 或空字符串时显示空态；JSON 解析失败时保留原文并显示行号，便于用户定位问题。

## 无障碍

树视图继承 JsonViewer 的展开、折叠和复制交互。标题和展开/折叠文案应本地化；空态不能只显示空白区域。
