GeoJSONView 是只读 GeoJSON 查看器。调用方传入预格式化 JSON 字符串；组件解析成功时渲染可折叠 JSON 树，空值、解析失败和不支持的 primitive 分别显示明确状态。

<RegistryInstall registryName="geojson-view" />

```tsx
import {
  GeoJSONView,
  stringifyGeoJSON,
  type GeoJSONViewLabels,
  type GeoJSONViewProps,
} from "@/registry/blocks/geojson-view"
```

## 用法

用 `stringifyGeoJSON(data)` 在调用方生成字符串，再把结果传入 `json`。没有选中要素时传 `null`，并用 `emptyLabel` 提供本地化空态。

## 公开导出与 Props

导出 `GeoJSONView`、`stringifyGeoJSON`、`GeoJSONViewProps` 和 `GeoJSONViewLabels`。关键 props 是 `json`、`emptyLabel`、`title`、`expandAllLabel`、`collapseAllLabel`、`copyFeedbackDurationMs`、`labels` 和 `className`。`labels` 可注入展开、收起、复制、复制完成、单复数计数、解析错误和不支持值等全部用户可见文案。

## 状态、空态与错误

组件是纯展示，不保存选中要素。`json` 为 null 或空字符串时显示空态；JSON 解析失败时以 `alert` 状态保留原文和行号；解析为 primitive 时显示独立的 warning 状态。

## 无障碍

树视图使用 Base UI 的折叠触发器，提供展开状态、内容关联、键盘操作和统一 focus ring。标题、工具栏、计数与状态文案都应本地化；空态不能只显示空白区域。
