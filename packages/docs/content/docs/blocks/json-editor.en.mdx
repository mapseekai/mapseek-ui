JsonEditor is a CodeMirror 6 JSON editor. It formats an object as editable JSON, calls `onChange` with parsed objects, and keeps invalid in-progress text visible until the user fixes it.

## Usage

Pass any JSON value plus `onChange`. `theme` defaults to `"app"`, which uses Mapseek semantic tokens and follows the host light/dark mode. `"light"` and `"dark"` are complete standalone themes that do not depend on the host theme. `"none"` injects no component color palette, so the caller owns appearance through inherited styles, class overrides, CSS, or extensions. Specialist embeds can also provide a complete CodeMirror `Extension`. A string `title` renders a header, while `null` hides it.

## Public Exports and Props

Exports include `JsonEditor`, `JsonEditorProps`, and `JsonEditorTheme`; `JsonEditorTheme` is `"app" | "light" | "dark" | "none" | Extension`. Key props are `value`, `onChange`, `title`, `ariaLabel`, `theme`, `onFocus`, `onBlur`, `withScroll`, `className`, `editorClassName`, `headerClassName`, and `titleClassName`.

## States and Validation

The component stores editor text and focus state internally. `onChange` fires only when `JSON.parse` succeeds, so the caller can keep showing the last valid value while the user repairs invalid JSON.

## Accessibility

With a visible `title`, the component uses that title to label both the outer field group and the CodeMirror textbox. Without a title, use `ariaLabel` to describe the editor purpose. The editor keeps internal caret, selection, and active-line feedback, but focus does not change the outer border or add an outer ring. Outer UI should provide save, reset, or error messaging and avoid shortcut conflicts with CodeMirror focus.
