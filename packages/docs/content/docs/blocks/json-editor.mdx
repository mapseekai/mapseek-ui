JsonEditor 是基于 CodeMirror 6 的 JSON 编辑器。它把对象格式化为可编辑 JSON，解析成功时通过 `onChange` 回传对象，解析失败时保留用户正在输入的无效文本。

```tsx
  type JsonEditorProps,
  type JsonEditorTheme,
} from "@/registry/blocks/json-editor"
```

## 用法

传入任意 JSON 值和 `onChange`。`theme` 默认为 `"app"`，使用 Mapseek 语义 token 并跟随宿主明暗模式；`"light"` 和 `"dark"` 是不受宿主主题影响的完整独立主题；`"none"` 不注入组件配色，由调用方通过继承样式、class 覆盖、CSS 或扩展负责外观。特殊嵌入场景也可以传入完整的 CodeMirror `Extension`。`title` 为字符串时显示标题栏，为 `null` 时隐藏。

## 公开导出与 Props

导出 `JsonEditor`、`JsonEditorProps` 和 `JsonEditorTheme`；`JsonEditorTheme` 为 `"app" | "light" | "dark" | "none" | Extension`。关键 props 是 `value`、`onChange`、`title`、`ariaLabel`、`theme`、`onFocus`、`onBlur`、`withScroll`、`className`、`editorClassName`、`headerClassName` 和 `titleClassName`。

## 状态与校验

组件内部保存编辑文本和焦点状态。只有 JSON.parse 成功时才触发 `onChange`；因此调用方可以继续显示上一个有效值，同时让用户修复无效 JSON。

## 无障碍

有可见 `title` 时，组件会用标题同时标记外层字段组和 CodeMirror 文本框；无标题时使用 `ariaLabel` 描述编辑器目的。编辑器保留光标、选区和活动行等内部反馈，但获得焦点时不会改变外层边框或添加外层光环。外层应提供保存、重置或错误说明，并确保 CodeMirror 焦点不会与页面快捷键冲突。
