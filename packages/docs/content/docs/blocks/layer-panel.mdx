LayerPanel 是面向地图工程的受控图层面板，包含分组、搜索、可见性筛选、当前图层和面板折叠状态。

## 安装

<RegistryInstall registryName="layer-panel" />

## 导入

```tsx
import { LayerPanel, type LayerData } from "@/components/blocks/layer-panel"
```

## 受控状态

通过 `layers`、`selectedId`、`query`、`visibleOnly`、`collapsedGroups` 和对应处理器接入项目状态。每个 `LayerData` 图层提供分组、geometry、要素数量和可见性。可见文案统一由 `labels` 注入。
