## Usage

Pass grouped `LinkedRefGroup[]` plus icons for each kind. Card tabs summarize each group, while the selected panel shows names, IDs, times, and status; summary cards stack into one column on narrow screens.

## Public Exports and Props

Exports include `LinkedRefList`, `LinkedRefGroup`, `LinkedRefItem`, `LinkedRefItemAction`, `LinkedRefItemActions`, `LinkedRefKind`, and `LinkedRefStatusTone`. Optional `itemActions` injects distinct labels and callbacks for `open` and `copyLink`; omitted actions are not rendered.

## Loading, Empty, Error, and Status

The list owns only the selected group; data loading, empty groups, and errors are controlled by the caller deciding whether to render this block.

## Accessibility

Group summaries use standard tab/tabpanel semantics and support arrow-key navigation. Kind and action icons are decorative and hidden from assistive technology; status Tags include text and structure, not color-only meaning.
