## Usage

Pass grouped `LinkedRefGroup[]` plus icons for each kind. Summary cards own counts, while rows show names, IDs, times, and status.

## Public Exports and Props

Exports include `LinkedRefList`, `LinkedRefGroup`, `LinkedRefItem`, `LinkedRefKind`, and `LinkedRefStatusTone`. `openLabel` names pending open/copy actions.

## Loading, Empty, Error, and Status

The list owns only the selected group; data loading, empty groups, and errors are controlled by the caller deciding whether to render this block.

## Accessibility

Summary cards are buttons and support keyboard switching. Status pills include text and structure, not color-only meaning.
