LinkedRefList 汇总数据集、地图集和工作流引用，帮助用户判断资源被哪些对象消费或派生。

## 安装

<RegistryInstall registryName="linked-ref-list" />

## 导入

```tsx
import {
  LinkedRefList,
  type LinkedRefGroup,
  type LinkedRefKind,
  type LinkedRefListProps,
} from "@/registry/blocks/linked-ref-list"
```

## 引用关系分组

<ShowcaseDemo registryName="linked-ref-list" title="引用关系分组" description="示例复用同一个 TSX 模块作为预览和源码，覆盖原示例的核心状态与交互。" minHeight={520} />

## 用法

传入分组后的 `LinkedRefGroup[]` 和每类图标。分组 summary 负责概览数量，条目行负责名称、ID、时间和状态。

## 公开导出与 Props

导出 `LinkedRefList`、`LinkedRefGroup`、`LinkedRefItem`、`LinkedRefKind` 和 `LinkedRefStatusTone`。`openLabel` 用于暂未接入的跳转/复制动作。

## 加载、空态、错误与状态

列表选择状态在组件内部；数据加载、空分组和错误由调用方决定是否渲染本组件。

## 无障碍

summary 卡片是按钮，可键盘切换。状态 pill 包含文字和结构，不依赖颜色单独表达。
