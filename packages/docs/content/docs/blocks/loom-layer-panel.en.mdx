LoomLayerPanel is a controlled layer panel for map projects with grouping, search, visibility filtering, current-layer selection, and panel collapse state.

## Controlled state

Connect project state through `layers`, `selectedId`, `query`, `visibleOnly`, `collapsedGroups`, and the matching handlers. All visible copy is injectable through `labels`.
