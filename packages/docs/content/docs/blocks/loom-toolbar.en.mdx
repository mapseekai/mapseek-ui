LoomToolbar is a controlled map-editing toolbar that composes editing state, tool groups, snapping, save, and undo/redo controls.

## Tool model

Each tool provides an `id`, `label`, `icon`, and optional shortcut. Tools marked `editOnly` are disabled outside editing mode. The product owns persistence, history, and map interaction.
