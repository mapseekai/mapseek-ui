MapControls is the familiar bottom-right zoom, locate, and home control cluster for map canvases. It only owns vertical button layout, icons, and tooltips; zoom level, geolocation permissions, map-instance calls, and status feedback belong to the caller.

## Usage

Place the component inside a relatively positioned map container and use `className` to anchor it to a corner. `onZoomIn` and `onZoomOut` are required handlers; `onLocate` and `onHome` are optional, and their buttons are not rendered when omitted. All copy is injected through `labels`.

## Public Exports and Props

Exports include `MapControls`, `MapControlsProps`, and `MapControlsLabels`. Key props are `onZoomIn`, `onZoomOut`, `onLocate`, `onHome`, `labels`, and `className`. The component does not read a map instance or store current zoom or location state.

## Controlled State

The control itself has no business state. The example writes each button callback to outer status text; real apps usually call MapLibre, deck.gl, or a project map controller from those callbacks and handle permission failures, locating state, and animation state outside.

## Accessibility

Each button uses its label as `aria-label`, and the tooltip is only visual reinforcement. Ensure other overlays in the map container do not cover the controls, and provide readable feedback when the locate action fails.
