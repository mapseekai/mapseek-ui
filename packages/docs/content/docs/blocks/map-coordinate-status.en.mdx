MapCoordinateStatus is a CRS switcher and coordinate readout for map canvases. It renders the current CRS, center point, zoom or scale, and delegates CRS selection to CrsPicker; map view state, projection transforms, and reload behavior stay with the caller.

## Usage

Pass controlled `crs`, current `center`, and `zoom`. If the map only exposes scale, pass `scale` as a fallback. For fully custom display, pass `readouts`; it replaces the default center and level readouts. `allowedEpsgs` and `extraItems` are forwarded to the internal CrsPicker.

## Public Exports and Props

Exports include `MapCoordinateStatus`, `MapCoordinateStatusProps`, `MapCoordinateStatusReadout`, and `MapCoordinateStatusLabels`. Key props are `crs`, `center`, `zoom`, `scale`, `readouts`, `onCrsChange`, `allowedEpsgs`, `extraItems`, `labels`, `className`, and `pickerClassName`.

## Controlled State

The component only owns popover open state. `crs` and `view` must be updated by the caller; the demo's `applyCrs` changes both CRS and sample coordinates to model how a real map refreshes center after a projection change.

## Accessibility

The CRS trigger uses `labels.switchCrs`, and readout items use localized labels. Longitude/latitude and projected coordinates should retain units or direction. The popup CRS list inherits CrsPicker search, list labeling, and empty-result behavior.
