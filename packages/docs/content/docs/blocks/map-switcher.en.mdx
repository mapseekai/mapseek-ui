MapSwitcher is a basemap switcher built on the Dropdown Menu primitives. It exposes Trigger, Panel, and Item as a compound component with two variants: `icon` (layers-icon trigger with a compact list panel) and `image` (thumbnail trigger showing the selected basemap with a thumbnail grid panel). Basemap data, selected value, open state, and basemap side effects stay with the caller.

## Usage

Place `MapSwitcher` in a map overlay and compose `MapSwitcher.Trigger`, `MapSwitcher.Panel`, and multiple `MapSwitcher.Item` children inside it. With `variant="icon"` the trigger is a layers-icon button and the panel is a compact list; with `variant="image"` the trigger shows the selected basemap thumbnail and the panel presents a thumbnail grid whose checked tile carries the card-type selection treatment: a primary 5% fill with a 1px primary ring. For controlled mode, pass `value`, `onChange`, `open`, and `onOpenChange`.

## Public Exports and Props

Exports include `MapSwitcher`, `MapSwitcherProps`, and `MapSwitcherItemData`. Root props are `value`, `defaultValue`, `onChange`, `open`, `defaultOpen`, `onOpenChange`, `variant`, and `children`. `MapSwitcher.Trigger` accepts `label` (accessible label for the icon variant) and `className`. Items require `id` and `label`, with optional `image` and `color`.

## Controlled State

The selected basemap and popup open state can be controlled or uncontrolled. The third demo controls both `value` and `open`, so external buttons can toggle the popup or advance to the next basemap, showing how callers can synchronize basemap state with a map engine. The popup closes automatically after a basemap is selected.

## Accessibility

The component is built on Dropdown Menu: the trigger automatically gets `aria-haspopup="menu"` and `aria-expanded`, the panel uses `role="menu"`, and items use `role="menuitemradio"` with `aria-checked`. Basemap thumbnails need readable labels, and remote images should not be the only source of information.
