MapSwitcher is a basemap switcher. It exposes Trigger, Panel, and Item as a compound component, supports thumbnail image mode and compact button-list mode, and leaves basemap data, selected value, open state, and basemap side effects to the caller.

## Usage

Place `MapSwitcher` in a map overlay and compose `MapSwitcher.Trigger`, `MapSwitcher.Panel`, and multiple `MapSwitcher.Item` children inside it. In image mode, pass `image` to items; in button mode, `color` and `label` are enough. For controlled mode, pass `value`, `onChange`, `open`, and `onOpenChange`.

## Public Exports and Props

Exports include `MapSwitcher`, `MapSwitcherProps`, and `MapSwitcherItemData`. Root props are `value`, `defaultValue`, `onChange`, `open`, `defaultOpen`, `onOpenChange`, `mode`, `className`, and `children`. Items require `id` and `label`, with optional `image` and `color`.

## Controlled State

The selected basemap and panel open state can be controlled or uncontrolled. The third demo controls both `value` and `open`, so external buttons can toggle the panel or advance to the next basemap, showing how callers can synchronize basemap state with a map engine.

## Accessibility

Trigger uses `aria-expanded` and `aria-haspopup="listbox"`, Panel uses `role="listbox"`, and Item uses `role="option"` with `aria-selected`. Basemap thumbnails need readable labels, and remote images should not be the only source of information.
