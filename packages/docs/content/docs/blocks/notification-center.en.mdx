## Usage

Pass controlled `items`, localized labels, and `streamActive`. Clear all, clear one, and retry are delegated through callbacks.

## Public Exports and Props

Exports include `NotificationCenter`, `NotificationCenterItem`, `NotificationCenterLabels`, `NotificationCenterStatusTone`, and props. State props include `isLoading`, `isError`, and `streamActive`.

## Loading, Empty, Error, and Status

The block includes loading skeletons, retryable error, empty state, and populated summaries. Demo buttons cover all four paths.

## Accessibility

The trigger uses `labels.trigger` as its accessible name; the dropdown inherits keyboard and focus handling from DropdownMenu.
