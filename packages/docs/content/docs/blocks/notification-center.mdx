NotificationCenter 是 header 中的通知 Popover，展示处理任务、来源、流状态和清理动作。

## 安装

<RegistryInstall registryName="notification-center" />

## 导入

```tsx
import {
  NotificationCenter,
  type NotificationCenterItem,
  type NotificationCenterLabels,
  type NotificationCenterProps,
} from "@/registry/blocks/notification-center"
```

## 用法

传入受控 `items`、本地化 labels 和 `streamActive`。清空、单条清理和重试都通过回调交给调用方。

## 公开导出与 Props

导出 `NotificationCenter`、`NotificationCenterItem`、`NotificationCenterLabels`、`NotificationCenterStatusTone` 和 props 类型。状态字段包括 `isLoading`、`isError`、`streamActive`。

## 加载、空态、错误与状态

组件内置 loading skeleton、错误重试、空态和有数据 summary。示例按钮覆盖四条路径。

## 无障碍

触发器的可访问名称会组合 `labels.trigger` 与当前数量、加载或错误状态。通知面板使用 Popover 语义和正常的 Tab 顺序；单条清除动作在对应 item 悬停或获得键盘焦点时出现，并在触屏设备上保持可见。按 Escape 关闭后焦点返回触发器，数量及异步状态变化通过 polite live region 宣布。
