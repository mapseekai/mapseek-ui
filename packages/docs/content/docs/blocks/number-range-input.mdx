NumberRangeInput 把数字输入框和单滑块组合在一起，适合透明度、缩放级别、百分比和其他有 min/max 的数值配置。

## 用法

传入受控 `value`、`min`、`max`、`step` 和 `onChange`。用户可以拖动滑块，也可以直接输入数字；失焦后组件会根据范围和 step 归一化显示。

未传入 `value` 时，`defaultValue` 提供真实的非受控初始值。受控模式下传入 `value={undefined}` 会清空数值；由调用方决定这是否应显示为必填错误。

## 公开导出与 Props

导出 `NumberRangeInput` 和 `NumberRangeInputProps`。关键 props 是 `value`、`defaultValue`、`min`、`max`、`step`、`onChange`、`required`、`disabled`、`name`、`id`、`autoComplete`、`aria-label`、`aria-labelledby`、`aria-describedby`、`sliderAriaLabel`、`className`、`sliderClassName` 和 `inputClassName`。

## 状态与校验

组件保存编辑中字符串，合法值才通过 `onChange` 提交。滑块会 clamp 到 min/max 并按 step 舍入；小数 step 会限制显示精度。组件把内部编辑错误和调用方传入的 `aria-invalid` 合并；表单的提示与错误文案由调用方通过 `FieldDescription` 和 `FieldError` 提供，并使用 `aria-describedby` 关联。

数字 `Input` 使用标准 32px 高度。Slider 的滑块 thumb 与指针目标几何保持不变。

## 无障碍

每个实例必须有非空的可访问名称。没有可见标签时，直接传入 `aria-label`；该名称会用于数字输入，并默认用于 Slider thumb。使用可见的 `FieldLabel` 时，传入 `aria-labelledby` 指向标签 ID，**同时必须**传入非空 `sliderAriaLabel` 作为 Slider thumb 名称。

为数字输入提供稳定的 `id`，使用 `aria-describedby` 关联提示和错误信息，并在需要时传入 `autoComplete`。滑块和数字框都支持键盘操作；调用方拥有 `FieldDescription`、`FieldError`、本地化文案和外部 `aria-invalid` 状态。
