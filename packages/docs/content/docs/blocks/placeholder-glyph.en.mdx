PlaceholderGlyph hashes a seed into a stable monochrome SVG for resource grids, drawers, and sprite previews before real icons are uploaded.

## Usage

Pass a stable `seed` for each resource, control pixel size with `size`, and use `mono` for lower visual weight. Pass a localized `title` when the glyph independently carries image meaning.

## Public Exports and Props

Exports include `PlaceholderGlyph` and `PlaceholderGlyphProps`. Key props are `seed`, `size`, `mono`, `title`, and `className`.

## Loading, Empty, Error, and Status

The component has no internal state; callers usually fall back to it when real SVG, sprite, or font previews are missing.

## Accessibility

Without `title`, the SVG is decorative and hidden from the accessibility tree, which suits named buttons, cards, and sprite cells. When the glyph independently carries image meaning, pass a localized `title`; the component creates a unique title ID and exposes it through `role="img"` and `aria-labelledby`.
