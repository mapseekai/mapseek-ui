## Usage

Pass ordered `TimelineStep[]`. Each step can be done, active, pending, or failed, with optional percent progress, messages, and events.

## Public Exports and Props

Exports include `ProcessingTimeline`, `TimelineStep`, `TimelineEvent`, `ProcessingTimelineLabels`, and props. An error event shows the Log action only when it includes `log` and the caller provides `onLogClick`; callers can open a log dialog or panel from that callback.

## Loading, Empty, Error, and Status

Progress, failure, and retry state all come from props; `progressKind` supports `percent`, `indeterminate`, and `none`. An empty steps array renders the standard Empty state, and the demo covers active percent progress and a completed history with an error retry.

## Accessibility

Steps render as an ordered list; state markers have text alternatives, and progress bars use a named `role="progressbar"` with aria values. Long step labels truncate with their full value in a title, event content wraps to avoid horizontal overflow, and motion is disabled when users prefer reduced motion.
