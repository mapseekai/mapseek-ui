ProcessingTimeline 渲染上传、入库、发布等长任务步骤，包含进度条、标准 Tag 状态标记、事件卡和错误日志入口。

<RegistryInstall registryName="processing-timeline" />

## 导入

```tsx
import {
  ProcessingTimeline,
  type ProcessingTimelineLabels,
  type TimelineEvent,
  type TimelineStep,
} from "@/registry/blocks/processing-timeline"
```

## 用法

传入有序 `TimelineStep[]`。每步可以是 done、active、pending 或 failed，并可携带 percent 进度、消息和事件。

## 公开导出与 Props

导出 `ProcessingTimeline`、`TimelineStep`、`TimelineEvent`、`ProcessingTimelineLabels` 和 props。错误事件包含 `log` 且传入 `onLogClick` 时会显示“日志”操作；调用方可在回调中打开日志弹框或面板。

## 加载、空态、错误与状态

进度、失败和重试都来自 props；`progressKind` 支持 `percent`、`indeterminate` 和 `none`。传入空数组时使用标准 Empty 状态，示例覆盖 active percent 与完成后含错误重试的历史流程。

## 无障碍

步骤使用有序列表；状态标记提供文本化状态，进度条使用带名称的 `role="progressbar"` 与 aria 数值。长步骤名会截断并保留完整 title，事件内容会自动换行以避免横向溢出；动效在减少动态效果偏好下会关闭。
