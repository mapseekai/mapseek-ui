ResourceDetailDrawer is the resource-library detail drawer for icon, sprite, and font details, including font slicing configuration.

```tsx
  type ResourceDetailDrawerProps,
} from "@/registry/blocks/resource-detail-drawer"
```

## Usage

Pass the selected resource as the discriminated union `ResourceDetail`. Close, copy, download, sprite edit, and slice execution are caller callbacks.

## Public Exports and Props

Exports include `ResourceDetailDrawer`, `ResourceDetail`, `IconDetail`, `SpriteDetail`, `FontDetail`, `SliceCharset`, and props.

## Loading, Empty, Error, and Status

The drawer is controlled by the passed `detail` and outer open state; the demo covers all three detail kinds plus close, copy, download, and slice states.

## Accessibility

The drawer inherits Sheet portal behavior, focus trapping, and Escape close. Keep action labels explicit.
