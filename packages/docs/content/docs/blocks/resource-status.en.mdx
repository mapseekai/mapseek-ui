## Usage

Pass semantic `tone` and localized `label`. Tone controls icon and color, while label keeps status from being color-only.

## Public Exports and Props

Exports include `ResourceStatusBadge`, `ResourceStatusBadgeProps`, and `ResourceStatusTone`. Tone can be `ready`, `processing`, `failed`, or `neutral`.

## Loading, Empty, Error, and Status

The component has no internal state; processing tone shows a spinner icon. The demo cycles current state and displays every tone.

## Accessibility

Always include a text label for status; do not rely on icon color alone inside tables or cards.
