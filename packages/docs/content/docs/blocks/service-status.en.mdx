<ShowcaseDemo registryName="service-status" title="Service running state" description="The preview and source share the same TSX module and show the core states and interactions." minHeight={360} />

## Usage

Pass `running` to control state; pass `onChange` for interaction and omit it for read-only display. `variant` can be framed or inline.

## Public Exports and Props

Exports include `ServiceStatus`, `ServiceStatusProps`, `ServiceStatusLabels`, and `DEFAULT_SERVICE_STATUS_LABELS`. Key props are `running`, labels, `onChange`, `disabled`, and `variant`.

## Loading, Empty, Error, and Status

Running/stopped, disabled, and inline/framed states are props-driven; the demo covers read-only, interactive, and disabled states.

## Accessibility

The internal Switch supports keyboard toggling; adjacent status text keeps running state from relying on color or animation.
