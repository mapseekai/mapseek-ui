StatStrip shows a small set of key metrics at the top of detail views, suited to dataset, raster, and service summaries.

## Usage

Pass an `items` array with label and value plus optional unit, icon, badge, and mono. The wrapper owns responsive scrolling or wrapping.

## Public Exports and Props

Exports include `StatStrip`, `StatItem`, and `StatStripProps`. The component only receives `items`.

## Loading, Empty, Error, and Status

The component has no internal state; loading/empty/error should be replaced by skeleton, empty, or error summaries in the wrapper. The demo switches between two metric sets.

## Accessibility

Every item needs a text label. Icons and badges are supplementary and should not replace metric names.
