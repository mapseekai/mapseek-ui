## Usage

Control `open` and `onOpenChange` from the caller, and compose modal content with the exported parts. Keep short save flows in the modal; use a side panel or drawer for long property editing.

## Public Exports and Props

Exports include `StyleEditorModal`, `StyleEditorModalSection`, `StyleEditorModalAlert`, `StyleEditorModalTile`, `StyleEditorModalSourceCard`, `StyleEditorModalActions`, and their props.

## Loading, Empty, Error, and Status

Use `StyleEditorModalAlert` for errors. Save, cancel, and template selection state belongs to the product layer. In the demo, save and cancel both close the dialog and update status text.

## Accessibility

Pass a readable `title`, and make trigger and close actions legible. Portal content should stay within the viewport, and Escape or button close should return focus to the trigger context.
