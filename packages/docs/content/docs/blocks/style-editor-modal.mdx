StyleEditorModal 提供样式编辑任务的统一 dialog 外壳，并配套 section、alert、tile、source card 和 actions。

## 安装

<RegistryInstall registryName="style-editor-modal" />

## 导入

```tsx
import {
  StyleEditorModal,
  StyleEditorModalActions,
  type StyleEditorModalProps,
} from "@/registry/blocks/style-editor-modal"
```

## 弹窗、提示与保存

<ShowcaseDemo registryName="style-editor-modal" title="弹窗、提示与保存" description="示例覆盖 portal 渲染、提示关闭、模板选择、保存和取消状态。" minHeight={520} />

## 用法

由调用方控制 `open` 和 `onOpenChange`，弹窗内容使用导出的组合件组织。短保存流程放在 modal 内，长属性编辑应使用侧栏或抽屉。

## 公开导出与 Props

导出 `StyleEditorModal`、`StyleEditorModalSection`、`StyleEditorModalAlert`、`StyleEditorModalTile`、`StyleEditorModalSourceCard`、`StyleEditorModalActions` 和对应 props 类型。

## 加载、空态、错误与状态

错误提示使用 `StyleEditorModalAlert`；保存、取消和模板选择状态由业务层持有。示例中保存和取消都会关闭 dialog 并更新状态文本。

## 无障碍

标题传入 `title`，触发器和关闭动作必须有可读文案。portal 内容应保持在视口内，Escape 和按钮关闭后应返回触发上下文。
