StyleFilterEditor provides row layout, single-condition layout, inline errors, action areas, and unsupported states for style filter editing.

## Usage

Callers provide property inputs, operator selects, and value inputs. `StyleFilterEditorRow` handles row and action layout, while `StyleFilterEditorSingle` only defines the single-condition grid.

## Public Exports and Props

Exports include row, single, actions, inline error, unsupported, info components, and their props. The block does not parse MapLibre filter syntax.

## Loading, Empty, Error, and Status

Show empty states in the wrapper. Use `StyleFilterEditorInlineError` for invalid conditions and `StyleFilterEditorUnsupported` with an upgrade action for nested expressions that cannot be edited.

## Accessibility

Every input and select needs a label. Remove buttons must identify the target condition, and error text should stay adjacent to the affected filter area.
