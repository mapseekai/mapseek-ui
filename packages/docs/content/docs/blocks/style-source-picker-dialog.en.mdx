StyleSourcePickerDialog is a portal dialog for adding style sources, with search, source filters, type filters, and multi-select confirmation.

## Usage

Pass `options`, `alreadyAddedKeys`, `loading`, and `confirming` from the caller. On confirm, the component returns the selected option objects.

## Public Exports and Props

Exports include `StyleSourcePickerDialog` and option, draft, filter, label, and props types. Filtering and selection helpers are installed with the component files.

## Loading, Empty, Error, and Status

`loading` shows loading text, `loadErrorMessage` can pair with `onRetryLoad`, and `confirmErrorMessage` displays confirmation failures. Empty search results use localized empty copy.

## Accessibility

Search, filter toggles, and confirm controls need localized labels. Already-added items are disabled and also show a badge, so the reason is not color-only or interaction-only.
