StyleSourcePickerDialog 是样式编辑器添加数据源的 portal dialog，支持搜索、来源过滤、类型过滤和多选确认。

## 安装

<RegistryInstall registryName="style-source-picker-dialog" />

## 导入

```tsx
import {
  StyleSourcePickerDialog,
  type StyleSourcePickerDialogProps,
  type StyleSourcePickerOption,
} from "@/registry/blocks/style-source-picker-dialog"
```

## 用法

调用方传入 `options`、`alreadyAddedKeys`、`loading` 和 `confirming`。确认时组件返回选中的完整 option 数组。

## 公开导出与 Props

导出 `StyleSourcePickerDialog` 以及 option、draft、filter、label 和 props 类型。过滤和选择 helper 随组件文件安装。

## 加载、空态、错误与状态

`loading` 显示加载文本，`loadErrorMessage` 可配合 `onRetryLoad`，`confirmErrorMessage` 显示确认失败。空搜索结果使用本地化 empty 文案。

## 无障碍

搜索框、过滤 toggle 和确认按钮都需要本地化文案。已添加项禁用但仍显示 badge，避免只靠不可点击状态传达原因。
