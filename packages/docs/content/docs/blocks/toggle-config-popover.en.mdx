## Usage

Control `checked` and `onCheckedChange` from the caller, and render threshold, target, or other configuration fields as children. `open` can be controlled or left to internal popover state.

## Public Exports and Props

Exports include `ToggleConfigPopover`, `ToggleConfigPopoverProps`, and labels types. Pass a Tabler icon component as the `icon` prop.

## Loading, Empty, Error, and Status

The component does not handle async saving. Disabled state disables both the main switch and settings trigger. Loading, error, and save status inside the configuration form belong to the child content.

## Accessibility

The main button uses `role="switch"` and `aria-checked`. Provide `toggleLabel`, `triggerLabel`, `switchLabel`, and tooltip text so icon buttons have readable names.
