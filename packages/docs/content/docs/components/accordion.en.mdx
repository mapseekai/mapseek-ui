Accordion folds related explanations, settings, or help content into scannable sections. Use it for FAQ, property notes, and advanced settings, not for data that must stay visible together.

## Exports

`accordion.tsx` exports `Accordion`, `AccordionItem`, `AccordionTrigger`, and `AccordionContent`. The root inherits Base UI Accordion props; `multiple` allows several items to stay open.

## States and Behavior

Use `defaultValue` for static defaults and `value/onValueChange` for controlled flows. `AccordionTrigger` swaps chevrons from `aria-expanded`, and `AccordionContent` animates height and opacity.

## Accessibility

Each trigger should describe the panel content. Do not hide critical state only inside collapsed content; keyboard users need a predictable trigger for each section.
