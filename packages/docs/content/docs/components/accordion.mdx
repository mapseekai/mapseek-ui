Accordion 用于把同一主题下的说明、设置或帮助内容折叠成可扫描的区块。它适合 FAQ、属性说明和高级设置，不适合承载必须同时阅读的核心数据。

## 安装

<RegistryInstall registryName="accordion" />

## 导入

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/registry/ui/accordion"
```

## 导出

`accordion.tsx` 导出 `Accordion`、`AccordionItem`、`AccordionTrigger` 和 `AccordionContent`。根组件继承 Base UI Accordion props；`multiple` 允许多个 item 同时展开。

## 状态与行为

`defaultValue` 适合静态默认展开，`value/onValueChange` 适合受控流程。`AccordionTrigger` 会根据 `aria-expanded` 切换上下箭头，`AccordionContent` 使用高度与透明度动画展示开合。

## 无障碍

每个触发器文本应准确描述内容区。不要把重要状态只放在折叠内容内；键盘用户需要能通过 trigger 进入和离开每个区块。
