Alert presents an inline status, validation result, or error that needs immediate attention. It standardizes the layout for an icon, title, description, and optional action instead of making each business component rebuild a callout.

## Exports

`Alert` is the root, `AlertTitle` and `AlertDescription` structure its copy, and `AlertAction` contains a recovery action. `variant` supports `default` and `destructive`.

## Accessibility

The component uses `role="alert"` by default for dynamic results that need immediate announcement. Override it with a less disruptive semantic role for static guidance when appropriate. Never communicate status through color alone; explain the state and the next step in text.
