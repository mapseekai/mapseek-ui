Badge is a compact marker for state, category, and metadata. Use it for publication status, CRS, format, and error level; do not use it as a replacement for buttons or full help text.

## Exports

`Badge` exports the component and `badgeVariants` exports the class-variance-authority style helper. The component renders a `span` by default and can change host elements through Base UI `render`.

## States and Behavior

`variant` supports `default`, `secondary`, `destructive`, `outline`, `ghost`, and `link`. When rendered as a link, hover styles stay aligned through the `[a]` selectors.

## Accessibility

State text must explain itself; use “Error” rather than only a red color. Clickable badges should render as links or buttons with a clear purpose.
