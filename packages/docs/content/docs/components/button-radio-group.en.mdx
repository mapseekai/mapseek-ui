Button Radio Group presents a radio group as a connected segmented control. It retains Base UI keyboard, focus, and form semantics, requires a choice by default, and wraps options when horizontal space runs out.

## Installation

<RegistryInstall registryName="button-radio-group" />

## Import

```tsx
import { ButtonRadioGroup, ButtonRadioGroupItem } from "@/registry/ui/button-radio-group"
```

## Usage

<ShowcaseDemo registryName="button-radio-group" demo="overview" title="Dynamically added button choices" description="Choose one active layer or add more options. Buttons wrap in a narrow container while the group retains single-selection behavior." minHeight={300} />

```tsx
const [value, setValue] = useState("layer-1")
const [options, setOptions] = useState([
  { label: "Layer 1", value: "layer-1" },
  { label: "Layer 2", value: "layer-2" },
])

<ButtonRadioGroup value={value} onValueChange={setValue} aria-label="Choose an active layer">
  {options.map((option) => (
    <ButtonRadioGroupItem key={option.value} value={option.value}>
      {option.label}
    </ButtonRadioGroupItem>
  ))}
</ButtonRadioGroup>
```

## Behavior

`ButtonRadioGroup` sets `required` by default. Pass `defaultValue` or a controlled `value` to ensure an option is selected on first render. Add options by updating its children; the selected item remains selected. Items share the available width on each row, while their labels remain on one line at their natural minimum width.

## Accessibility

Give `ButtonRadioGroup` an `aria-label` or `aria-labelledby`. `ButtonRadioGroupItem` keeps the radio role and arrow-key navigation; clicking the selected item again does not clear it.
