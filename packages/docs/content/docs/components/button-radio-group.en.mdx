Button Radio Group presents a radio group as a connected segmented control. It retains Base UI keyboard, focus, and form semantics, supports icons and four heights, and wraps options when horizontal space runs out.

## Behavior

The `ButtonRadioGroupItem` `icon` prop composes with every existing `variant`, `size`, and state, and scales the icon with the group size. `variant` accepts a solid `default` selected state or a `soft` state using the shared `selection-bg` token. The soft treatment matches selected states in Segmented, FilterPanel, and Table. `size` accepts `xs`, `sm`, `default`, or `lg`, mapping to 24px, 28px, 32px, and 36px heights. It defaults to the 32px `default` size. The component sets `required` by default; pass `defaultValue` or a controlled `value` to provide an initial selection.

## Accessibility

Give `ButtonRadioGroup` an `aria-label` or `aria-labelledby`. An icon-only `ButtonRadioGroupItem` also needs an `aria-label` describing the option; the supplied icon is treated as decorative. `ButtonRadioGroupItem` keeps the radio role and arrow-key navigation; clicking the selected item again does not clear it.
