Chart provides Mapseek UI wrappers for Recharts containers, theme variables, Tooltip, and Legend. Use it for feature counts, service metrics, and processing statistics.


## Exports

`ChartContainer` provides context and CSS variables. `ChartTooltip` and `ChartLegend` reuse Recharts primitives, while `ChartTooltipContent` and `ChartLegendContent` provide Mapseek UI styling.

## States and Behavior

`ChartConfig` maps data keys to labels, icons, and colors. The container creates `--color-*` variables and supports different values for light and dark themes.

## Accessibility

Prefer enabling `accessibilityLayer` on Recharts charts, and provide key values in nearby prose or tables. Do not rely on color alone to distinguish series.
