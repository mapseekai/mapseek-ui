## Exports

`checkbox.tsx` exports `Checkbox`. The component inherits Base UI Checkbox root props, including `checked/onCheckedChange`, `defaultChecked`, `disabled`, and `aria-invalid`.

## States

Use `checked/onCheckedChange` for controlled flows and `defaultChecked` for static defaults. Disabled removes interaction and lowers opacity; invalid uses `aria-invalid` for destructive border and ring styles.

## Accessibility

Pair every checkbox with `Label` or `aria-label`. Do not communicate selection or errors with color alone; place error text near the field or render it with `FieldError`.
