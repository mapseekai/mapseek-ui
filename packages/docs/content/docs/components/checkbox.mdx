Checkbox 用于布尔选择、批量选择和可选设置。它保留 Base UI 的键盘与焦点语义，并使用 Mapseek 的方角、边框优先状态样式。

## 导出

`checkbox.tsx` 导出 `Checkbox`。组件继承 Base UI Checkbox root props，可使用 `checked/onCheckedChange`、`defaultChecked`、`disabled` 和 `aria-invalid`。

## 状态

受控流程使用 `checked/onCheckedChange`；静态默认值使用 `defaultChecked`。禁用态移除交互并降低透明度，错误态通过 `aria-invalid` 增加 destructive 边框和 ring。

## 无障碍

为每个 checkbox 绑定 `Label` 或 `aria-label`。不要只用颜色表达选择或错误；错误说明应靠近字段或由 `FieldError` 呈现。
