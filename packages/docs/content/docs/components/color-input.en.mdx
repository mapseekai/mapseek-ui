Color Input is the foundational color field. It combines a swatch, text input, and custom color picker for forms that need precise input and visual color selection.

## Exports

`color-input` exports `ColorInput`, the lower-level `ColorPicker` parts, and their types. `ColorInput` supports `value/onTextChange`, `defaultValue`, `disabled`, `mode`, `layout`, and `aria-label`; business components can add domain semantics on top.

## Accessibility

Provide a readable `aria-label` or associated label. When users need to identify an exact color, display its text value as well instead of relying on the swatch alone.
