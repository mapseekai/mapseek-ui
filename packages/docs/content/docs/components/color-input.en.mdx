## Exports

`color-input.tsx` exports `ColorInput`. It inherits native `input[type=color]` attributes including `value/onChange`, `defaultValue`, `disabled`, and `aria-label`.

## Accessibility

Provide a readable `aria-label` or associated label. When users need to identify an exact color, display its text value as well instead of relying on the swatch alone.
