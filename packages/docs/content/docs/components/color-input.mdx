Color Input 是基础颜色输入组件，组合色块、文本输入和自定义颜色选择器，适合需要精确输入与可视化选色的表单。

## 安装

<RegistryInstall registryName="color-input" />

## 导入

```tsx
import { ColorInput } from "@/registry/ui/color-input"
```

<ShowcaseDemo registryName="color-input" demo="overview" title="受控值与禁用状态" description="可以通过色块打开自定义颜色选择器，也可以直接输入颜色值；修改后会立即同步，并展示不可交互的禁用状态。" minHeight={320} />

## 导出

`color-input` 导出 `ColorInput`、底层 `ColorPicker` 组合件和对应类型。`ColorInput` 支持 `value/onTextChange`、`defaultValue`、`disabled`、`mode`、`layout` 和 `aria-label`；业务组件可以在此基础上封装领域语义。

## 无障碍

为颜色输入提供可读的 `aria-label` 或关联标签，并在需要精确识别颜色时同步显示文本值，不要只依赖色块传达信息。
