Combobox is a searchable single-value selector for formats, coordinate systems, or resources. It composes input-group, a portal list, empty state, clear button, and trigger button.

## Exports

`combobox.tsx` exports `Combobox`, `ComboboxInput`, `ComboboxContent`, `ComboboxList`, `ComboboxItem`, `ComboboxEmpty`, `ComboboxGroup`, `ComboboxLabel`, `ComboboxValue`, `ComboboxTrigger`, `ComboboxClear`, and chips components.

## States

Use `value/onValueChange` to control the input and selected value. Render `ComboboxEmpty` when filtering returns no options. `showTrigger` renders the dropdown button, `showClear` renders the clear button, and `disabled` passes to the input and buttons.

## Accessibility

Give the input a clear `aria-label` or visible label. Items need stable `value` props; keyboard users should be able to use typing, arrow keys, Enter, and Escape.
