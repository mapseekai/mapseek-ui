Confirm Dialog provides promise-based confirmation flows for save, export, and destructive delete actions that must wait for an explicit user choice.

<ShowcaseDemo registryName="confirm-dialog" demo="overview" title="Confirmation flows" description="Covers destructive, default, fallback cancel text, and result state and shows delete, save, and export flows." minHeight={360} />

## Exports

`confirm-dialog.tsx` exports `ConfirmProvider` and `useConfirm`. `useConfirm` accepts `title`, `description`, `confirmText`, `cancelText`, and `variant`, then returns `Promise<boolean>`.

## States

Use `variant="destructive"` for irreversible actions. Default confirmations fit save and export flows; canceling resolves to `false`.

## Accessibility

Place `ConfirmProvider` near the application root. Trigger buttons must name the target action; confirmation dialogs need clear titles, result-oriented button text, Escape close, and trigger focus return.
