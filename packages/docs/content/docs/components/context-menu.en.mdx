## Exports

`context-menu.tsx` exports root, trigger, content, group, label, item, checkbox item, radio group, submenu, separator, and shortcut components.

## States

Items support `disabled` and `variant="destructive"`. Checkbox items use `checked/onCheckedChange`; radio items live inside `ContextMenuRadioGroup`; nested actions use `ContextMenuSub`.

## Accessibility

The trigger region must be focusable and keyboard reachable. After opening, the menu should support arrow navigation, Enter selection, Escape close, and focus return. Do not make right click the only path to critical actions.
