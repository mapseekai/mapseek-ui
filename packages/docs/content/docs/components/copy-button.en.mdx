CopyButton copies short texts such as identifiers and paths, in icon and text variants. After a successful copy it switches to a check confirmation and reverts after a short delay.

## Exports

`copy-button.tsx` exports `CopyButton`. The component accepts `content` (text to copy), `variant="icon" | "text"`, `label`, `copiedLabel`, `duration`, and `onCopy` / `onCopyError` callbacks.

## States

The button shows the copy icon or `label` by default; after a successful copy it shows a check and `copiedLabel`, reverting after `duration` milliseconds. When the clipboard is unavailable it triggers `onCopyError`.

## Accessibility

The icon variant must carry an `aria-label` describing the copy target; the confirmation state updates the accessible name so screen readers perceive the result.
