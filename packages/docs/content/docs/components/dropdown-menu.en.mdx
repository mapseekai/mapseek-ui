## Exports

`dropdown-menu.tsx` exports root, trigger, portal, content, group, label, item, checkbox item, radio group, submenu, separator, and shortcut components.

## States

Use `align`, `side`, and offsets to control portal placement. Use `disabled` for unavailable items and `variant="destructive"` for dangerous actions.

## Accessibility

Use a real button trigger with an accessible name. Open menus should support arrow keys, Home/End, Enter selection, Escape close, and trigger focus return.
