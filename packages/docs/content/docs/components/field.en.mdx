## Exports

`field.tsx` exports `FieldSet`, `FieldLegend`, `FieldGroup`, `Field`, `FieldContent`, `FieldLabel`, `FieldTitle`, `FieldDescription`, `FieldSeparator`, and `FieldError`. `FieldLabel` and `FieldLegend` accept `required`, which appends a destructive-red `*` after the field name.

## States

`orientation` supports `vertical`, `horizontal`, and `responsive`. Invalid fields use `data-invalid="true"` together with control-level `aria-invalid`; disabled fields can use field-level `data-disabled` to affect labels.

## Accessibility

`FieldError` uses `role="alert"`. Labels should point to real controls; use `required` on required labels and retain matching native `required` or `aria-required` semantics on the control; error text should explain the format, impact, and recovery path.
