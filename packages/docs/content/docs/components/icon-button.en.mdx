IconButton is for icon-only tool actions such as edit, download, refresh, and delete. It is always square; `label` supplies the required accessible name, and `danger` expresses destructive actions.

## Usage

<ShowcaseDemo registryName="icon-button" demo="overview" title="Icon button states" description="Covers the 24/28/32/36/40px size scale, danger and disabled states, and the built-in tooltip." minHeight={336} />

```tsx
import { IconPencil } from "@tabler/icons-react"

</IconButton>
```

## Exports

`icon-button.tsx` exports `IconButton`. It accepts Base UI Button props plus required `label`, optional `tooltip`, `size="xs" | "sm" | "md" | "lg" | "xl"` (24/28/32/36/40px), and `danger`; the default size is `md`.

`xl` is the 40px top-level-toolbar tier with a 20px icon; use it only when the inner toolbar row is at least 40px high.

## States

Default buttons use muted hover styles; `danger` uses destructive foreground and a tinted background. `disabled` removes pointer interaction and lowers opacity; every size stays square with a zero radius and shows a 3px ring on keyboard focus.

## Accessibility

`label` is the required accessible name and maps directly to `aria-label`. `tooltip` is off by default; `true` shows `label`, while a string supplies custom text. Enable it only when the symbol is not self-evident; destructive actions still need confirmation or undo at the workflow layer.
