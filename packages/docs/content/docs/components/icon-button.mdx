IconButton 用于仅包含图标的工具操作，例如编辑、下载、刷新和删除。它保持正方形尺寸，并通过 `danger` 表达破坏性动作。

## 导出

`icon-button.tsx` 导出 `IconButton`。组件继承原生 `button` props，并额外接受 `size="sm" | "md"` 和 `danger`。

## 状态

普通按钮使用 muted hover；`danger` 使用 destructive 前景和淡背景。`disabled` 移除指针交互并降低透明度。

## 无障碍

每个图标按钮必须提供 `aria-label`；含义不明显时同时提供 `title` 或外层 tooltip。危险操作仍需在流程层确认或支持撤销。
