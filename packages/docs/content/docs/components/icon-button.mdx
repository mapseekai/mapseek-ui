IconButton 用于仅包含图标的工具操作，例如编辑、下载、刷新和删除。它始终为正方形；`label` 提供必填的可访问名称，`danger` 表达破坏性动作。

## 导出

`icon-button.tsx` 导出 `IconButton`。它接受 Base UI Button props，以及必填 `label`、可选 `tooltip`、`size="xs" | "sm" | "md" | "lg" | "xl"`（24/28/32/36/40px）和 `danger`；默认尺寸为 `md`。

`xl` 是 40px 的顶级工具栏档位，内部图标为 20px；仅在内部工具栏行高至少为 40px 时使用。

## 状态

普通按钮使用 muted hover；`danger` 使用 destructive 前景和淡背景。`disabled` 移除指针交互并降低透明度；所有尺寸均保持零圆角，键盘聚焦显示 3px ring。

## 无障碍

`label` 是必填的可访问名称，并原样映射为 `aria-label`。`tooltip` 默认关闭；传入 `true` 显示 `label`，传入字符串显示自定义文本。仅在符号不自明时启用 tooltip；破坏性操作仍需在流程层确认或支持撤销。
