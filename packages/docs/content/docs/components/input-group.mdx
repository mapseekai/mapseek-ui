InputGroup 用于把 input、textarea、图标、单位和内嵌按钮组合到同一个边界内。它适合搜索、坐标、单位值和多行备注。

## 安装

<RegistryInstall registryName="input-group" />

## 导入

```tsx
import { InputGroup, InputGroupAddon, InputGroupInput, InputGroupText } from "@/registry/ui/input-group"
```

## 导出

`input-group.tsx` 导出 `InputGroup`、`InputGroupAddon`、`InputGroupButton`、`InputGroupInput`、`InputGroupText` 和 `InputGroupTextarea`。

## 状态

addon 可使用 `inline-start`、`inline-end`、`block-start` 或 `block-end`。子控件 `aria-invalid` 会提升到 group 边界；禁用子控件会降低整体可用性样式。

## 无障碍

addon 不替代 label。搜索、坐标和备注输入仍应拥有可见 label 或 `aria-label`；单位文本应避免成为唯一的错误提示。
