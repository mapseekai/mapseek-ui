Input is the base single-line text input for names, coordinate systems, file names, and short identifiers. It inherits Base UI Input and applies Mapseek's 32px control rhythm.

## Exports

`input.tsx` exports `Input`. The component inherits native `input` props, including `value/onChange`, `defaultValue`, `readOnly`, `disabled`, `aria-invalid`, and `type`.

## States

Controlled inputs use `value/onChange`; read-only fields stay focusable and copyable; disabled fields are for non-interactive states only. Invalid state uses `aria-invalid`.

## Accessibility

Every input needs `Label`, `aria-label`, or `aria-labelledby`. Error copy should render near the field rather than relying on a red border alone.
