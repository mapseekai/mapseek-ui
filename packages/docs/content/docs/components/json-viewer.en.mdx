JsonViewer displays structured JSON in docs, debug panels, and data detail views. It supports node collapse, expand all, collapse all, copy, and optional colored indentation.

## Exports

`json-viewer.tsx` exports `JsonViewer`. It accepts `data`, `title`, `defaultExpanded`, `showLineNumbers`, `showColorIndent`, `collapseOn`, and copy-feedback props.

## States and Behavior

`defaultExpanded` can be a boolean or expansion depth number. Object and array nodes can be collapsed, and toolbar buttons expand all, collapse to the root, or copy formatted JSON.

## Accessibility

Give the JSON region a clear title. Copy controls need readable labels, and deeply nested data should have nearby context for source and important fields.
