JsonViewer displays structured JSON in docs, debug panels, and data detail views. It supports node collapse, expand all, collapse all, copy, and optional colored indentation.

## Exports

`json-viewer.tsx` exports `JsonViewer`. It accepts `data`, `title`, `defaultExpanded`, `showLineNumbers`, `showColorIndent`, `collapseOn`, `expandAllLabel`, `collapseAllLabel`, `copyLabel`, `copiedLabel`, `itemLabel`, `itemsLabel`, `copyContent`, and `copyFeedbackDurationMs`.

## States and Behavior

`defaultExpanded` can be a boolean or expansion depth number. Object and array nodes support click or double-click collapse, and toolbar buttons expand all, collapse to the root, or copy formatted JSON. Copied feedback appears only after a successful clipboard write; failures preserve the idle state.

## Accessibility

Give the JSON region a clear title. Collapsible controls expose `aria-expanded` and associated content, copy controls have readable labels, and all toolbar controls share a 24px height and the design-system focus ring. Deeply nested data should have nearby context for source and important fields.
