Pagination provides page navigation with semantic `nav`, list structure, current-page state, and previous/next controls.

<RegistryInstall registryName="pagination" />

## Import

```tsx

  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
} from "@/registry/ui/pagination"
```

## Exports

`pagination.tsx` exports `Pagination`, `PaginationContent`, `PaginationItem`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, and `PaginationEllipsis`.

## States

`PaginationLink isActive` sets `aria-current="page"` and active visual state. Previous and next links can clamp or disable based on the current page.

## Accessibility

Keep the `nav` semantics and readable link text. The current page must use `aria-current="page"`; ellipsis should represent skipped ranges, not the only way to navigate.
