Pagination 用于分页导航，保持语义 `nav`、列表结构、当前页标记和上一页/下一页入口。

## 安装

<RegistryInstall registryName="pagination" />

## 导入

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
} from "@/registry/ui/pagination"
```

## 用法

<ShowcaseDemo registryName="pagination" demo="overview" title="分页导航" description="覆盖当前页、上一页、下一页、首尾页和省略号状态，展示受控页码行为。" minHeight={180} />

## 导出

`pagination.tsx` 导出 `Pagination`、`PaginationContent`、`PaginationItem`、`PaginationLink`、`PaginationPrevious`、`PaginationNext` 和 `PaginationEllipsis`。

## 状态

`PaginationLink isActive` 会设置 `aria-current="page"` 并使用 active 视觉状态。上一页/下一页可根据当前页禁用或限制目标页。

## 无障碍

保留 `nav` 语义和可读链接文本。当前页必须有 `aria-current="page"`；省略号应只表示跳过区间，不应成为唯一导航方式。
