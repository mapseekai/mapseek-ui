Progress communicates task completion or work that is still running but cannot be quantified. Use it for tile generation, dataset analysis, uploads, and background jobs.

## Exports

`Progress` is the root. `ProgressTrack`, `ProgressIndicator`, `ProgressLabel`, and `ProgressValue` map to Base UI progress slots.

## States and Behavior

A numeric `value` renders determinate progress; `null` represents indeterminate work. `ProgressValue` derives percentage text from the root value.

## Accessibility

Give long tasks a text label, and explain at the workflow layer whether users can cancel or leave the page. Do not show only an animated bar without a task name.
