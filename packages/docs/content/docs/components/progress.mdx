Progress 显示任务完成度或正在进行但无法量化的状态。它适合切片生成、数据分析、上传和后台处理任务。

## 安装

<RegistryInstall registryName="progress" />

## 导入

```tsx
import { Progress, ProgressIndicator, ProgressLabel, ProgressTrack, ProgressValue } from "@/registry/ui/progress"
```

## 导出

`Progress` 是根组件，`ProgressTrack`、`ProgressIndicator`、`ProgressLabel` 和 `ProgressValue` 对应 Base UI progress slots。

## 状态与行为

传入数字 `value` 会显示确定进度；传入 `null` 表示不确定状态。`ProgressValue` 会根据根组件 value 输出百分比文本。

## 无障碍

为长任务提供文本 label，并在业务层说明是否可取消或可离开页面。不要只显示动画条而没有任务名称。
