Select is a finite single-value picker for CRS, formats, and modes. It is built on Base UI Select and maps item labels back into the trigger value.

## Exports

`select.tsx` follows the standard composition API and exports `Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectGroup`, `SelectLabel`, `SelectItem`, `SelectSeparator`, and the scroll buttons. State props belong on the root; sizing and accessible labels belong on the trigger.

## States

Use `value/onValueChange` for controlled state and `defaultValue` for static defaults. `SelectTrigger size="sm"` provides the compact trigger; root-level `disabled` prevents opening the list.

## Accessibility

Selects without visible labels need `aria-label`. Keyboard users should be able to open with Enter/Space, move with arrow keys, choose with Enter, and close with Escape.
