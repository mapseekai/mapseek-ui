Select is a finite single-value picker for CRS, formats, and modes. It is built on Base UI Select and maps item labels back into the trigger value.

## Exports

`select.tsx` follows the standard composition API and exports `Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectGroup`, `SelectLabel`, `SelectItem`, `SelectSeparator`, and the scroll buttons. State props belong on the root; sizing and accessible labels belong on the trigger.

## States

Use `value/onValueChange` for controlled state and `defaultValue` for static defaults. `SelectTrigger` supports `xs`, `sm`, `default`, and `lg` heights, and every item in the popup matches its trigger height. The trigger defaults to `width="fixed"`; use `width="content"` to make its external width follow the selected value. When opened with a mouse and a value is selected, the popup aligns that item with the trigger by default; pass `alignItemWithTrigger={false}` to keep it below the trigger, with Base UI falling back automatically when space is limited. The popup always grows to the longest option; root-level `disabled` prevents opening the list.

## Accessibility

Selects without visible labels need `aria-label`. Keyboard users should be able to open with Enter/Space, move with arrow keys, choose with Enter, and close with Escape.
