Select 用于有限选项的单值选择，例如 CRS、格式和模式。它基于 Base UI Select，并把 item label 映射到 trigger value。

## 安装

<RegistryInstall registryName="select" />

## 导入

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/registry/ui/select"
```

## 导出

`select.tsx` 按标准组合方式导出 `Select`、`SelectTrigger`、`SelectValue`、`SelectContent`、`SelectGroup`、`SelectLabel`、`SelectItem`、`SelectSeparator` 和滚动按钮。状态属性放在根组件，尺寸和无障碍属性放在 trigger。

## 状态

受控值使用 `value/onValueChange`；静态默认值使用 `defaultValue`。`SelectTrigger size="sm"` 提供紧凑触发器；根组件的 `disabled` 阻止打开列表。

## 无障碍

为无可见 label 的 select 提供 `aria-label`。键盘用户应能通过 Enter/Space 打开、方向键移动、Enter 选择、Escape 关闭。
