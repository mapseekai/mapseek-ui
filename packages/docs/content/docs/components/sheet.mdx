Sheet 用于长内容、详情查看和保留页面上下文的局部任务。它基于 Dialog portal，并提供侧边或底部进入的面板结构。

## 安装

<RegistryInstall registryName="sheet" />

## 导入

```tsx
import {
  Sheet,
  SheetBody,
  SheetContent,
  SheetTrigger,
} from "@/registry/ui/sheet"
```

## 用法

<ShowcaseDemo registryName="sheet" demo="overview" title="资源详情与发布队列" description="覆盖 right 与 bottom 两种面板、header/body/footer 结构、关闭按钮和视口约束。" minHeight={220} />

## 导出

`sheet.tsx` 导出 `Sheet`、`SheetTrigger`、`SheetContent`、`SheetHeader`、`SheetTitle`、`SheetDescription`、`SheetBody`、`SheetFooter` 和 `SheetClose`。

## 状态

`side` 支持 `top`、`bottom`、`left` 和 `right`。为长内容设置宽度、高度和滚动边界，避免把页面主体挤出视口。

## 无障碍

每个 Sheet 必须有标题和可读关闭按钮。Escape 关闭和遮罩关闭应返回触发器焦点；长表单需要保留可见 footer 操作。
