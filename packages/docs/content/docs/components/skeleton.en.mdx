Skeleton is a loading placeholder for known content structure while data is still unavailable. It fits text rows, card content, and list placeholders.

## Import

```tsx

```

## Exports

`Skeleton` is a `div` with `data-slot="skeleton"` and standard `div` props. Callers control dimensions through `className`.

## States and Behavior

The default style uses `animate-pulse` and `bg-muted`. Placeholder dimensions should approximate final content to avoid layout shift after loading.

## Accessibility

Skeleton should not be announced as real content. Long loading regions need parent-level `aria-busy` or status text so screen-reader users know work is in progress.
