Switch represents immediate on/off settings such as cache, visibility, and sync state. Its default rounded track and thumb are an intentional exception to Mapseek's square control rule.

## Exports

`switch.tsx` exports `Switch`. The component inherits Base UI Switch root props and adds `size="sm" | "default"` plus `variant="default" | "square"`.

## Variants

Use the default rounded track for general settings. `variant="square"` preserves the compact 24×16px square-cornered switch used in configuration popover headers; reserve it for that dense configuration context rather than general forms.

## States

Use `checked/onCheckedChange` to control the switch, or `defaultChecked` for initial state. `disabled` marks it unavailable; `aria-invalid` marks an invalid setting.

## Accessibility

Switch needs an accessible name. Use it for immediate toggles, not form choices that require a Save action; those are usually better as Checkbox.
