Switch 表达立即生效的开关设置，例如缓存、可见性和同步状态。默认的圆形轨道与 thumb 是 Mapseek 方角规则中的有意例外。

## 导出

`switch.tsx` 导出 `Switch`。组件继承 Base UI Switch root props，并额外接受 `size="sm" | "default"` 与 `variant="default" | "square"`。

## 变体

默认圆形轨道用于一般设置。`variant="square"` 保留配置弹层头部使用的 24×16px 直角紧凑开关；仅用于这种高密度配置上下文，不应用于一般表单。

## 状态

使用 `checked/onCheckedChange` 控制开关，或用 `defaultChecked` 设置初始状态。`disabled` 表示不可切换，`aria-invalid` 表示当前设置无效。

## 无障碍

Switch 需要可读名称。它适合即时开关，不适合需要“保存”才能生效的普通表单选择；这类场景优先用 Checkbox。
