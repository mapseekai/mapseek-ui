Tabs 用于同一对象下的内容视图切换，例如<span className="whitespace-nowrap">概览</span>、字段结构、地图预览、导出设置和<span className="whitespace-nowrap">活动记录</span>。

## 安装

<RegistryInstall registryName="tabs" />

## 导入

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@/registry/ui/tabs"
```

`tabs.tsx` 导出 `Tabs`、`TabsList`、`TabsTrigger`、`TabsContent` 和 `tabsListVariants`。

## 状态

静态场景使用 `defaultValue`；受控场景使用 `value/onValueChange`。`TabsList variant="primary"` 使用主题色填充选中项，适合需要突出当前视图的场景；`variant="line"` 适合编辑器顶部标签，`orientation="vertical"` 适合侧向导航。带边框和完整项选中背景的场景请使用独立的 Card Tabs 组件。

## 无障碍

Trigger 文案应说明目标内容。键盘用户应能通过方向键移动、Enter/Space 激活，并跳过 disabled trigger。
