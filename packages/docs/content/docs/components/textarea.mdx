Textarea 用于多行短文本，例如备注、描述和错误详情。它保持 Mapseek 输入边界、焦点 ring、invalid 和 disabled 语义。

## 安装

<RegistryInstall registryName="textarea" />

## 导入

```tsx
import { Textarea } from "@/registry/ui/textarea"
```

## 导出

`textarea.tsx` 导出 `Textarea`。组件继承原生 `textarea` props，可使用 `value/onChange`、`defaultValue`、`readOnly`、`disabled`、`aria-invalid` 和 `rows`。

## 状态

受控输入由 `value/onChange` 驱动；只读文本保留选择与复制；禁用文本框表示当前不可编辑。错误态使用 `aria-invalid`。

## 无障碍

Textarea 需要可见 label 或 `aria-label`。长错误或帮助文本应由 `FieldDescription`、`FieldError` 或邻近说明承载。
