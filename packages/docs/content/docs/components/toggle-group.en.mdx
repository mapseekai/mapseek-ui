ToggleGroup combines ToggleGroupItem controls into single-select or multi-select groups for alignment, text style, map tool modes, and related options.

## Exports

`toggle-group.tsx` exports `ToggleGroup` and `ToggleGroupItem`. The root supports `value/onValueChange`, `variant`, `size`, `spacing`, and `orientation`.

## States

`value` is a string array, which can represent single or multiple selections. `spacing=0` can form a continuous outline group; disabled items ignore pointer and keyboard activation.

## Accessibility

Each item should name the option. Keyboard users should be able to move within the group and toggle with Enter/Space; state readout should not rely on background color alone.
