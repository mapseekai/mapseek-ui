Tooltip provides brief supplemental help such as icon button names, dangerous action hints, and toolbar assistance.

<RegistryInstall registryName="tooltip" />

## Import

```tsx

  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/registry/ui/tooltip"
```

## Exports

`tooltip.tsx` exports `TooltipProvider`, `Tooltip`, `TooltipTrigger`, and `TooltipContent`. Reuse an existing element with `TooltipTrigger render={<Button />}` and place the supplemental label inside `TooltipContent`.

## States

`TooltipContent` uses `side` for placement, `TooltipProvider` controls the default `delay`, and root-level `disabled` disables the overlay. Base UI's `render` prop composes an existing focusable trigger.

## Accessibility

Tooltip is only for short supplemental text, not critical task information or actions. Icon buttons still need `aria-label`; Tooltip should not be the only accessible name.
