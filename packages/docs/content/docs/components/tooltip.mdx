Tooltip 用于补充简短说明，例如图标按钮名称、危险动作提示和工具栏辅助信息。

## 安装

<RegistryInstall registryName="tooltip" />

## 导入

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/registry/ui/tooltip"
```

## 用法

<ShowcaseDemo registryName="tooltip" demo="overview" title="提示状态" description="覆盖 hover/focus 触发、四个方向、disabled 和图标工具栏提示。" minHeight={560} />

## 导出

`tooltip.tsx` 导出 `TooltipProvider`、`Tooltip`、`TooltipTrigger` 和 `TooltipContent`。将已有元素通过 `TooltipTrigger render={<Button />}` 作为触发器，并把提示文本放入 `TooltipContent`。

## 状态

`TooltipContent` 的 `side` 控制方向，`TooltipProvider` 的 `delay` 控制默认延迟，根组件的 `disabled` 禁用浮层。使用 Base UI 的 `render` 组合已有可聚焦元素。

## 无障碍

Tooltip 只能补充短文本，不能承载关键任务信息或可操作内容。图标按钮仍需要 `aria-label`；Tooltip 不应成为唯一可读名称。
