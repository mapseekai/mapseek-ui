Mapseek UI installs source through the shadcn registry. Components, blocks, utilities, and theme tokens are copied into your application repository, where your team owns the code after installation.

## components.json

First make sure shadcn is initialized and the application has a root `components.json`. If it is not initialized yet, run:

```bash
pnpm dlx shadcn@latest init
```

Then register the public Mapseek UI registry with the CLI:

```bash
pnpm dlx shadcn@latest registry add '@mapseek=https://mapseekai.github.io/mapseek-ui/r/{name}.json'
```

You can also add the same configuration to the application's `components.json` manually:

```json
{
  "registries": {
    "@mapseek": "https://mapseekai.github.io/mapseek-ui/r/{name}.json"
  }
}
```

The public registry is hosted on GitHub Pages. Open the [Button registry JSON](https://mapseekai.github.io/mapseek-ui/r/button.json) directly to check that the service is available.

## Install Commands

Install one component or block at a time with shadcn:

```bash
pnpm dlx shadcn@latest add @mapseek/button
pnpm dlx shadcn@latest add @mapseek/layer-panel
```

Install theme and utility dependencies the same way:

```bash
pnpm dlx shadcn@latest add @mapseek/theme
pnpm dlx shadcn@latest add @mapseek/utils
```

## Destinations

Primitive components install into the shadcn UI target, such as `@ui/button.tsx`. Complex blocks install into the application component area, such as `@components/blocks/layer-panel/LayerPanel.tsx`, `@components/blocks/layer-panel/types.ts`, and the same-directory `index.ts`.

Common imports after installation:

```tsx
import { Button } from "@/components/ui/button"
import { LayerPanel, type LayerData } from "@/components/blocks/layer-panel"
```

If your project uses different aliases, keep the installed file destinations and adjust only the import paths.

## Source Ownership

Mapseek UI is not a runtime component package. shadcn copies source into the application, and the application team owns review, commits, edits, and upgrades for those files. To upgrade later, rerun `pnpm dlx shadcn@latest add @mapseek/<name>` and review the resulting patch against local changes.
