Mapseek UI 通过 shadcn registry 安装源码。组件、业务组件、工具和主题 token 会复制到你的应用仓库中，后续修改由应用团队拥有。

## components.json

在应用的 `components.json` 中加入 Mapseek UI registry。`@mapseek` 命名空间指向同域发布的 registry JSON：

```json
{
  "registries": {
    "@mapseek": "https://mapseek-ui.local/r/{name}.json"
  }
}
```

本地预览或同域部署时，把域名换成站点域名即可；registry 路径保持 `/r/{name}.json`。

## 安装命令

使用 shadcn 安装单个组件或业务组件：

```bash
bunx shadcn@4.8.0 add @mapseek/button
bunx shadcn@4.8.0 add @mapseek/layer-panel
```

安装主题和工具依赖：

```bash
bunx shadcn@4.8.0 add @mapseek/theme
bunx shadcn@4.8.0 add @mapseek/utils
```

## 目标路径

Primitive 组件默认安装到 shadcn UI 目标，例如 `@ui/button.tsx`。复杂业务组件安装到应用组件区，例如 `@components/blocks/layer-panel/LayerPanel.tsx`、`@components/blocks/layer-panel/types.ts` 和同目录 `index.ts`。

安装后的常见导入：

```tsx
import { Button } from "@/components/ui/button"
import { LayerPanel, type LayerData } from "@/components/blocks/layer-panel"
```

如果你的项目别名不同，保持文件目标不变，只调整导入路径。

## 源码归属

Mapseek UI 不是运行时组件包。shadcn 会把源码复制进应用，应用团队负责审查、提交、修改和升级这些文件。后续升级建议重新运行 `bunx shadcn@4.8.0 add @mapseek/<name>`，再按应用差异审查补丁。
