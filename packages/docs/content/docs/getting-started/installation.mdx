Mapseek UI 通过 shadcn registry 安装源码。组件、业务组件、工具和主题 token 会复制到你的应用仓库中，后续修改由应用团队拥有。

## components.json

先确保应用已经初始化 shadcn，并且项目根目录存在 `components.json`。尚未初始化时运行：

```bash
pnpm dlx shadcn@latest init
```

然后使用 CLI 注册公开的 Mapseek UI registry：

```bash
pnpm dlx shadcn@latest registry add '@mapseek=https://mapseekai.github.io/mapseek-ui/r/{name}.json'
```

也可以手动在应用的 `components.json` 中加入相同配置：

```json
{
  "registries": {
    "@mapseek": "https://mapseekai.github.io/mapseek-ui/r/{name}.json"
  }
}
```

公开 registry 由 GitHub Pages 托管。可以直接打开 [Button registry JSON](https://mapseekai.github.io/mapseek-ui/r/button.json) 检查服务是否可用。

## 安装命令

使用 shadcn 安装单个组件或业务组件：

```bash
pnpm dlx shadcn@latest add @mapseek/button
pnpm dlx shadcn@latest add @mapseek/layer-panel
```

安装主题和工具依赖：

```bash
pnpm dlx shadcn@latest add @mapseek/theme
pnpm dlx shadcn@latest add @mapseek/utils
```

## 目标路径

Primitive 组件默认安装到 shadcn UI 目标，例如 `@ui/button.tsx`。复杂业务组件安装到应用组件区，例如 `@components/blocks/layer-panel/LayerPanel.tsx`、`@components/blocks/layer-panel/types.ts` 和同目录 `index.ts`。

安装后的常见导入：

```tsx
import { Button } from "@/components/ui/button"
import { LayerPanel, type LayerData } from "@/components/blocks/layer-panel"
```

如果你的项目别名不同，保持文件目标不变，只调整导入路径。

## 源码归属

Mapseek UI 不是运行时组件包。shadcn 会把源码复制进应用，应用团队负责审查、提交、修改和升级这些文件。后续升级建议重新运行 `pnpm dlx shadcn@latest add @mapseek/<name>`，再按应用差异审查补丁。
