The Mapseek UI docs site and shadcn registry are published by the same GitHub Pages static build. Component pages, guides, and registry JSON come from one public site for direct use, mirroring, internal deployment, and version pinning.

## Same-Domain Paths

Every installable item has same-domain JSON:

```text
https://mapseekai.github.io/mapseek-ui/r/button.json
https://mapseekai.github.io/mapseek-ui/r/layer-panel.json
https://mapseekai.github.io/mapseek-ui/r/theme.json
```

Use this registry template in `components.json`:

```json
{
  "registries": {
    "@mapseek": "https://mapseekai.github.io/mapseek-ui/r/{name}.json"
  }
}
```

shadcn resolves `@mapseek/button` to `https://mapseekai.github.io/mapseek-ui/r/button.json` and `@mapseek/layer-panel` to `https://mapseekai.github.io/mapseek-ui/r/layer-panel.json`.

## Local and Internal Deployments

When the static build is deployed on an internal domain or another base path, use the complete URL template for that deployment in `components.json`. No hosted search service or separate registry service is required.
