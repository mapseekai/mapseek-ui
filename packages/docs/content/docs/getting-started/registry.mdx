Mapseek UI 的文档站点和 shadcn registry 由同一个 GitHub Pages 静态构建发布。组件页面、指南和 registry JSON 来自同一个公开站点，便于直接使用、离线镜像、内部部署和版本固定。

## 同域路径

每个可安装条目都有一个同域 JSON：

```text
https://mapseekai.github.io/mapseek-ui/r/button.json
https://mapseekai.github.io/mapseek-ui/r/layer-panel.json
https://mapseekai.github.io/mapseek-ui/r/theme.json
```

在 `components.json` 中使用 registry 模板：

```json
{
  "registries": {
    "@mapseek": "https://mapseekai.github.io/mapseek-ui/r/{name}.json"
  }
}
```

shadcn 会把 `@mapseek/button` 解析为 `https://mapseekai.github.io/mapseek-ui/r/button.json`，把 `@mapseek/layer-panel` 解析为 `https://mapseekai.github.io/mapseek-ui/r/layer-panel.json`。

## 本地和内部部署

如果把静态构建部署在公司域名或其他子路径，`components.json` 中需要填写该部署对应的完整 URL 模板；不需要托管搜索服务，也不需要单独的 registry 服务。

## 检查 JSON

浏览器可以直接打开同域 registry 文件：

- [Button registry JSON](https://mapseekai.github.io/mapseek-ui/r/button.json)
- [LayerPanel registry JSON](https://mapseekai.github.io/mapseek-ui/r/layer-panel.json)
- [Theme registry JSON](https://mapseekai.github.io/mapseek-ui/r/theme.json)
