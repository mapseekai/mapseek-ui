# CrsPicker

CrsPicker 是坐标参考系选择器。它把内置 EPSG、搜索、分组和受控选择组合成一个地图产品常用控件；坐标转换、投影能力校验和地图引擎重载由调用方处理。

## 用法

默认不传 `allowedEpsgs` 时展示全部内置条目。需要限制地图引擎支持范围时传入 `allowedEpsgs`；需要追加工程私有 CRS 或覆盖内置名称时传入 `extraItems`。受控模式下传 `value` 和 `onChange`，非受控模式下传 `defaultValue`。

## 公开导出与 Props

导出 `CrsPicker`、`buildCrsList`、`DEFAULT_CRS_ITEMS`、`DEFAULT_CRS_PICKER_LABELS`、`CrsItem`、`CrsKind`、`CrsPickerProps` 和 `CrsPickerLabels`。关键 props 是 `value`、`defaultValue`、`onChange`、`allowedEpsgs`、`extraItems`、`labels` 和 `className`。

## 受控状态

组件可以自己维护初始选中值，也可以完全由调用方控制。示例中的外部按钮直接调用同一个 `handleChange`，用于模拟地图状态、URL 参数或工程配置从组件外部切换 CRS。

## 无障碍

触发器和搜索输入使用标签文案，列表用 `labels.listLabel` 命名，空结果使用 `labels.noResults`。调用方本地化 `labels` 时应保留 EPSG 代码本身，并让地理坐标系与投影坐标系分组名称保持可读。
