# FilterPanel

FilterPanel 是受控过滤构建器。它把 builder 行、SQL 文本、模式切换、统计估算、清空和应用按钮组合成一个紧凑面板，调用方保存过滤表达式并决定何时执行查询。

```tsx
import {
  EMPTY_FILTER,
  FilterPanel,
  type FilterCondition,
  type FilterPanelLabels,
  type FilterValue,

```

## 用法

用 `FilterValue` 保存当前过滤状态，把可用字段传给 `fields`，并在子组件中组合 `ModeToggle`、`Builder`、`Sql`、`Footer`、`Estimate`、`ClearButton` 和 `ApplyButton`。应用按钮通常触发外层查询或地图图层过滤。

## 公开导出与 Props

导出 `FilterPanel`、`EMPTY_FILTER`、`FilterCondition`、`FilterMode`、`FilterPanelProps`、`FilterPanelLabels` 和 `FilterValue`。关键 props 是 `fields`、`value`、`onChange`、`labels` 和 `children`；Builder 的操作符和 SQL 的关键词由调用方传入。

## 状态与校验

组件允许 builder 和 SQL 两种模式并保留各自草稿。字段、操作符和值的业务合法性由调用方在应用前校验；`EMPTY_FILTER` 可用于清空回到默认状态。

## 无障碍

模式切换、清空和应用都是按钮；字段、操作符和值控件有可读文本。调用方应把过滤结果数量和应用状态放入可感知文本，避免只用颜色表达有效或无效。
