# LayerStyleEditor

LayerStyleEditor 是右侧图层样式编辑器外壳。它统一标题栏、操作菜单、关闭按钮、底部 tabs 和内部 LayerEditorGroup；具体样式字段、数据页、JSON 页和保存逻辑由调用方组合。

## 用法

传入 `title`、`tabs` 和可选 `actions`。每个 tab 提供 `id`、`label` 和 `sections`，sections 会交给内部 `LayerEditorGroup` 渲染。删除、复制、隐藏、关闭和保存都应在调用方处理，组件只负责触发回调。

## 公开导出与 Props

导出 `LayerStyleEditor`、`LayerStyleEditorProps`、`LayerStyleEditorAction` 和 `LayerStyleEditorTab`。关键 props 是 `title`、`tabs`、`actions`、`defaultTabId`、`ariaLabel`、`actionMenuLabel`、`closeLabel`、`onClose` 和 className 覆盖项。

## 受控状态

Tab 初始值可用 `defaultTabId` 设置；字段值、图层选中、操作菜单结果和关闭行为由调用方状态拥有。示例中的 action 都是空回调，用来说明菜单项、禁用项和 destructive 项的形状。

## 无障碍

给编辑器设置 `ariaLabel`，给操作菜单设置 `actionMenuLabel`，给关闭按钮设置 `closeLabel`。Tab 文案应短且唯一。菜单中的 destructive 操作应有明确文本，并在真实应用中配合确认流程或可撤销反馈。
