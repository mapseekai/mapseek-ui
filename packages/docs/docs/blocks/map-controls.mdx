# MapControls

MapControls 是地图画布右下角常见的缩放、定位和归位控制组。它只负责竖向按钮布局、图标和 tooltip；缩放层级、定位权限、地图实例调用和状态反馈由调用方拥有。

## 用法

把组件放在相对定位的地图容器中，并用 `className` 定位到角落。`onZoomIn` 和 `onZoomOut` 是必需处理器；`onLocate` 和 `onHome` 可选，缺失时对应按钮不渲染。所有文案通过 `labels` 注入。

## 公开导出与 Props

导出 `MapControls`、`MapControlsProps` 和 `MapControlsLabels`。关键 props 是 `onZoomIn`、`onZoomOut`、`onLocate`、`onHome`、`labels` 和 `className`。组件不读取地图实例，也不保存当前 zoom 或定位状态。

## 受控状态

控件本身无内部业务状态。示例把每个按钮回调写入外层状态文本；真实应用通常会在回调中调用 MapLibre、deck.gl 或自有地图控制器，并在外层处理权限失败、定位中和动画中状态。

## 无障碍

每个按钮使用对应 label 作为 `aria-label`，tooltip 只作为视觉补充。调用方应确保地图容器中的其他 overlay 不遮挡按钮，定位按钮需要在权限失败时提供可读反馈。
