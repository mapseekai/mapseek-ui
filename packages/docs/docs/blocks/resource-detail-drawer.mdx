# ResourceDetailDrawer

ResourceDetailDrawer 是资源库详情抽屉，覆盖 icon、sprite 和 font 三类详情以及字体切片配置。

## 安装

<RegistryInstall registryName="resource-detail-drawer" />

## 导入

```tsx
import {
  ResourceDetailDrawer,
  type ResourceDetail,
  type ResourceDetailDrawerProps,
} from "@/registry/blocks/resource-detail-drawer"
```

## 用法

根据选中资源传入 discriminated union `ResourceDetail`。关闭、复制、下载、编辑 sprite 和执行切片都由调用方回调处理。

## 公开导出与 Props

导出 `ResourceDetailDrawer`、`ResourceDetail`、`IconDetail`、`SpriteDetail`、`FontDetail`、`SliceCharset` 和 props 类型。

## 加载、空态、错误与状态

抽屉由传入 `detail` 与外层 open 状态控制；示例覆盖三种详情、关闭、复制、下载和切片状态。

## 无障碍

抽屉继承 Sheet 的 portal、焦点陷阱和 Escape 关闭；按钮文案应保持动作明确。
