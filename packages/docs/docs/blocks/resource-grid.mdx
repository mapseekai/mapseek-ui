# ResourceGrid

ResourceGrid 是资源库主区域，按 icon、sprite 和 font 三种 tab 渲染不同密度的卡片布局。

## 安装

<RegistryInstall registryName="resource-grid" />

## 导入

```tsx
import {
  ResourceGrid,
  type ResourceGridItem,
  type ResourceGridProps,
  type ResourceTab,
} from "@/registry/blocks/resource-grid"
```

## 用法

传入当前 `tab`、对应 `items` 和打开/右键回调。icon 模式可传 `selectedIconIds` 与 `onIconSelect` 支持批量选择。

## 公开导出与 Props

导出 `ResourceGrid`、`ResourceGridItem`、三类 item 类型、`ResourceStatus`、`ResourceTab`、labels 和 props 类型。

## 加载、空态、错误与状态

空态通过 `empty` slot 注入；加载和错误由外层切换。示例覆盖 tab、选择、打开、右键菜单和空态。

## 无障碍

卡片是按钮，icon 选择复选框应提供 `iconSelectionLabel`。卡片名称会截断，完整名称应可从详情获取。
