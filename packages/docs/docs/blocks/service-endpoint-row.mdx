# ServiceEndpointRow

ServiceEndpointRow 展示单个 GET 服务地址，突出 URL 模板参数并提供复制和打开入口。

## 安装

<RegistryInstall registryName="service-endpoint-row" />

## 导入

```tsx
import { ServiceEndpointRow, type ServiceEndpointRowProps } from "@/registry/blocks/service-endpoint-row"
```

## 用法

传标题、副标题、URL、图标和回调。需要真实 token 或鉴权时可禁用打开按钮并通过 tooltip 说明。

## 公开导出与 Props

导出 `ServiceEndpointRow` 和 `ServiceEndpointRowProps`。关键 props 是 `title`、`subtitle`、`method`、`url`、`copyLabel`、`onCopy`、`openDisabled`、`openTooltip`、`onOpen`。

## 加载、空态、错误与状态

组件不直接访问剪贴板或窗口；复制、打开、禁用和错误提示均由外层回调/props 控制。

## 无障碍

复制和打开按钮必须提供 `copyLabel`、`openLabel`。URL 使用 code 区域并保持水平滚动。
