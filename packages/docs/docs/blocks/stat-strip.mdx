# StatStrip

StatStrip 在详情页顶部展示少量关键指标，适合数据集、栅格和服务摘要。

## 安装

<RegistryInstall registryName="stat-strip" />

## 导入

```tsx
import {
  StatStrip,
  type StatItem,
  type StatStripProps,
} from "@/registry/blocks/stat-strip"
```

## 用法

传 `items` 数组，每项包含 label、value，可选 unit、icon、badge 和 mono。外层负责响应式滚动或换行策略。

## 公开导出与 Props

导出 `StatStrip`、`StatItem` 和 `StatStripProps`。组件只接收 `items`。

## 加载、空态、错误与状态

组件无内部状态；loading/empty/error 应由外层替换为 skeleton、empty 或错误摘要。示例切换两组统计。

## 无障碍

每项必须有文本 label。icon 和 badge 是辅助信息，不应替代指标名称。
