# StorageMeter

StorageMeter 是本地存储用量 chip，展开后显示 OPFS、IndexedDB、Caches 等明细。

## 安装

<RegistryInstall registryName="storage-meter" />

## 导入

```tsx
import {
  StorageMeter,
  formatBytes,
  type StorageMeterData,
  type StorageMeterLabels,
  type StorageMeterProps,
} from "@/registry/blocks/storage-meter"
```

## 用法

把 `navigator.storage.estimate()` 或后端配额结果整理成 `StorageMeterData`，并传入 labels、刷新回调和可选 footer。

## 公开导出与 Props

导出 `StorageMeter`、`formatBytes`、`StorageMeterData`、`StorageMeterLabels` 和 props。关键 props 是 `data`、`loading`、`error`、`errorLabel`、`onRefresh`、`footer`。

## 加载、空态、错误与状态

支持正常、接近上限、unsupported、loading refresh 和 error 文案。示例覆盖正常、高水位和不支持三种数据。

## 无障碍

触发按钮的 aria-label 包含已用、配额和百分比；unsupported 分支通过 tooltip 解释原因。
