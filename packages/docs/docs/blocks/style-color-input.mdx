# StyleColorInput

StyleColorInput 将颜色 swatch、文本输入和可替换 picker 组合为一个受控颜色字段。

## 安装

<RegistryInstall registryName="style-color-input" />

## 导入

```tsx
import {
  StyleColorInput,
  type StyleColorInputProps,
} from "@/registry/blocks/style-color-input"
```

## 用法

使用 `value`、`open`、`onTextChange` 和 `onOpenChange` 实现完全受控输入。需要业务 picker 时传入 `renderPicker`，并通过 `close` 回调关闭 popover。

## 公开导出与 Props

导出 `StyleColorInput`、底层 `ColorPicker` 组合件，以及 `StyleColorInputMode`、`StyleColorInputLayout`、`StyleColorInputProps` 等类型。

## 加载、空态、错误与状态

组件不校验颜色格式；调用方应在保存前校验文本值，并用错误文本或状态栏说明无效输入。

## 无障碍

为文本输入传入 `aria-label`，为 swatch 传入 `swatchLabel`。popover 关闭后应保留在同一个编辑上下文中。
