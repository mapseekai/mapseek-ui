# StyleEditorPanel

StyleEditorPanel 提供样式编辑侧栏的标题栏、滚动内容、section、card 和 empty 组合件。

## 安装

<RegistryInstall registryName="style-editor-panel" />

## 导入

```tsx
import {
  StyleEditorPanelRoot,
  StyleEditorPanelCard,
  type StyleEditorPanelRootProps,
} from "@/registry/blocks/style-editor-panel"
```

## 用法

用 `StyleEditorPanelRoot` 固定侧栏边界，`StyleEditorPanelHeader` 放标题和动作，`StyleEditorPanelContent` 管理滚动，业务卡片放入 `StyleEditorPanelSection`。

## 公开导出与 Props

导出 root、header、content、section、card、empty 组件及其 props 类型。组件只负责布局和结构，不持有数据源状态。

## 加载、空态、错误与状态

空分组使用 `StyleEditorPanelEmpty`。加载和错误由调用方在 section 内切换；删除和新增等业务状态由外层维护。

## 无障碍

标题、删除按钮和新增按钮应有清晰文本或 `aria-label`。滚动区域需要保持键盘可达，卡片 action 不应只靠图标表达含义。
