# Card

Card 把标题、说明、内容和操作组织成一个边界清晰的内容单元。它适合数据集摘要、导出任务和图层详情，不适合页面级大容器嵌套。

## 安装

<RegistryInstall registryName="card" />

## 导入

```tsx
import { Card, CardAction, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/registry/ui/card"
```

## 导出

`Card` 是根容器，`CardHeader`、`CardTitle`、`CardDescription`、`CardAction`、`CardContent` 和 `CardFooter` 定义常用区域。`CardBody` 是 `CardContent` 的别名。

## 状态与行为

`size="sm"` 会收紧间距。`CardAction` 在 header 网格右侧对齐，`CardFooter` 自动加上顶部边界并适合放置按钮组。

## 无障碍

Card 本身没有交互语义。需要整卡点击时应使用链接或按钮承载交互，并保证标题、描述和操作目标不会互相冲突。
