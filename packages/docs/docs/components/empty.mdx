# Empty

Empty 用于列表、面板或搜索结果没有内容时的空状态。它把图标、标题、说明和可选操作组合在一起，避免每个页面各自实现不同空态。

## 安装

<RegistryInstall registryName="empty" />

## 导入

```tsx
import { Empty, EmptyContent, EmptyDescription, EmptyHeader, EmptyMedia, EmptyTitle } from "@/registry/ui/empty"
```

## 导出

`Empty` 是根容器，`EmptyHeader` 组合媒体、标题和描述，`EmptyMedia` 支持 `default` 与 `icon` 变体，`EmptyContent` 放置操作按钮或辅助内容。

## 状态与行为

空状态应根据业务原因选择是否提供操作。可恢复的空列表通常提供主操作；搜索无结果更适合提供改筛选条件的说明。

## 无障碍

标题要直接说明“没有什么”，描述要说明原因或下一步。不要只用图标表达空状态，也不要把主要操作藏在图标按钮里。
