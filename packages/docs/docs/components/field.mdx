# Field

Field 组合 label、description、error 和控件布局，用于保持表单字段间距、错误状态和响应式方向一致。

## 安装

<RegistryInstall registryName="field" />

## 导入

```tsx
import { Field, FieldDescription, FieldError, FieldLabel } from "@/registry/ui/field"
```

## 用法

<ComponentDemo title="字段布局" description="覆盖基础字段、错误字段、水平 checkbox 字段和禁用字段，保留 Showcase 的 label/description/error 组合。" source={overviewSource} minHeight={420}>
  <FieldOverviewDemo />
</ComponentDemo>

## 导出

`field.tsx` 导出 `FieldSet`、`FieldLegend`、`FieldGroup`、`Field`、`FieldContent`、`FieldLabel`、`FieldTitle`、`FieldDescription`、`FieldSeparator` 和 `FieldError`。

## 状态

`orientation` 支持 `vertical`、`horizontal` 和 `responsive`。错误态使用 `data-invalid="true"` 搭配控件的 `aria-invalid`；禁用态可由字段层 `data-disabled` 统一影响标签。

## 无障碍

`FieldError` 使用 `role="alert"`。字段 label 应绑定实际控件；错误文本说明格式、影响和修复方式。
