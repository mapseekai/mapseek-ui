# Switch

Switch 表达立即生效的开关设置，例如缓存、可见性和同步状态。它使用圆形轨道与 thumb，是 Mapseek 方角规则中的例外。

## 安装

<RegistryInstall registryName="switch" />

## 导入

```tsx
import { Switch } from "@/registry/ui/switch"
```

## 导出

`switch.tsx` 导出 `Switch`。组件继承 Base UI Switch root props，并额外接受 `size="sm" | "default"`。

## 状态

使用 `checked/onCheckedChange` 控制开关，或用 `defaultChecked` 设置初始状态。`disabled` 表示不可切换，`aria-invalid` 表示当前设置无效。

## 无障碍

Switch 需要可读名称。它适合即时开关，不适合需要“保存”才能生效的普通表单选择；这类场景优先用 Checkbox。
