# Mapseek UI

Mapseek UI 是一套面向地图、空间数据和运维界面的 shadcn 源码组件。安装时组件会进入你的应用源码树，方便团队审查、调整和长期维护。

## 安装方式

使用 shadcn 将组件源码安装到项目中，而不是把 Mapseek UI 当作运行时组件包引入。组件源码、样式 token 和依赖声明来自本仓库的 registry 输出。

```bash
bun run registry:build
```
