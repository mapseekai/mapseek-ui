# AttrInspector

AttrInspector is a floating attribute panel for one feature. It supports read and edit modes, field metadata, enum editing, read-only primary key hints, confirm/cancel, delete, close, view GeoJSON, and add-field actions.

## Usage

Pass the current `feature`, field metadata `fields`, `mode`, controlled `draft`, and `onFieldChange`. Read mode fits inspection and GeoJSON entry points; edit mode lets an outer controller submit or discard draft changes.

## Public Exports and Props

Exports include `AttrInspector`, `inferAttrFieldKind`, `AttrFieldMeta`, `AttrInspectorFeature`, `AttrInspectorLabels`, `AttrInspectorMode`, and `AttrInspectorProps`. Main props are `feature`, `mode`, `fields`, `draft`, `onFieldChange`, `labels`, `onConfirm`, `onCancel`, `onDelete`, `onViewGeoJSON`, `onAddField`, `onClose`, and `className`.

## States and Validation

The block does not persist feature data. Draft values override `feature.properties` for display; confirm and cancel are caller-owned. Primary key fields are inferred as read-only, and enum fields render from `AttrFieldMeta.enumOptions`.

## Accessibility

Panel actions are native buttons with label text. When used as a floating map panel, the outer app should manage initial focus, Escape close behavior, and conflicts with map canvas shortcuts.
