# JsonEditor

JsonEditor is a CodeMirror 6 JSON editor. It formats an object as editable JSON, calls `onChange` with parsed objects, and keeps invalid in-progress text visible until the user fixes it.

## Usage

Pass any JSON value plus `onChange`. The default `theme="app"` uses Mapseek tokens; use `light`, `dark`, or `none` for isolated previews. A string `title` renders a header, while `null` hides it.

## Public Exports and Props

Exports include `JsonEditor`, `JsonEditorProps`, and `JsonEditorTheme`. Key props are `value`, `onChange`, `title`, `ariaLabel`, `theme`, `onFocus`, `onBlur`, `withScroll`, `className`, `editorClassName`, `headerClassName`, and `titleClassName`.

## States and Validation

The component stores editor text and focus state internally. `onChange` fires only when `JSON.parse` succeeds, so the caller can keep showing the last valid value while the user repairs invalid JSON.

## Accessibility

Use `ariaLabel` to describe the editor purpose. Outer UI should provide save, reset, or error messaging and avoid shortcut conflicts with CodeMirror focus.
