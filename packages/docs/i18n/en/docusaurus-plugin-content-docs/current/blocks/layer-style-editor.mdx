# LayerStyleEditor

LayerStyleEditor is the right-side shell for editing a layer style. It standardizes the header, action menu, close button, footer tabs, and internal LayerEditorGroup; concrete style fields, data pages, JSON pages, and save behavior are composed by the caller.

## Usage

Pass `title`, `tabs`, and optional `actions`. Each tab provides `id`, `label`, and `sections`, which render through the internal `LayerEditorGroup`. Delete, duplicate, hide, close, and save behavior should be handled by the caller; the component only triggers callbacks.

## Public Exports and Props

Exports include `LayerStyleEditor`, `LayerStyleEditorProps`, `LayerStyleEditorAction`, and `LayerStyleEditorTab`. Key props are `title`, `tabs`, `actions`, `defaultTabId`, `ariaLabel`, `actionMenuLabel`, `closeLabel`, `onClose`, and className overrides.

## Controlled State

The initial tab can be set with `defaultTabId`; field values, selected layer, action-menu results, and close behavior belong to caller state. The demo actions are no-op callbacks that show the shape of menu items, disabled items, and destructive items.

## Accessibility

Set `ariaLabel` on the editor, `actionMenuLabel` on the action menu, and `closeLabel` on the close button. Tab labels should be short and unique. Destructive menu actions need clear text and should be paired with confirmation or undo feedback in real apps.
