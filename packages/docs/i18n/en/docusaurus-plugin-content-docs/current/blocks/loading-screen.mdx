# LoadingScreen

LoadingScreen is a fullscreen or container-scoped loading placeholder for map initialization, resource refreshes, and long-running jobs.

## Installation

<RegistryInstall registryName="loading-screen" />

## Import

```tsx
import {
  LoadingScreen,
  DEFAULT_LOADING_SCREEN_LABELS,
  type LoadingScreenLabels,
  type LoadingScreenProps,
} from "@/registry/blocks/loading-screen"
```

## Usage

Pass `text` for the primary message and `description` for the second line; `fullscreen` switches to viewport sizing.

## Public Exports and Props

Exports include `LoadingScreen`, `LoadingScreenProps`, `LoadingScreenLabels`, and `DEFAULT_LOADING_SCREEN_LABELS`. Key props are `text`, `description`, `fullscreen`, `labels`, and `className`.

## Loading, Empty, Error, and Status

This is the loading branch; empty and error branches should switch to Empty or error panels instead of leaving the spinner visible.

## Accessibility

The root uses `role="status"` and `aria-live="polite"`, suitable for non-blocking status updates.
