# PixelProbe

PixelProbe is a read-only raster pixel probe panel for TiTiler `/point` or similar query results. It owns the header, field rows, type badges, lock marker, copy button, close button, and pixel stepper footer; querying, copy payloads, and close state are handled by the caller.

## Usage

Convert query results into `PixelField[]`, with each row providing `key`, `type`, and `value`, plus optional `unit` and `locked`. Pass `count` and `index` to show the point count and current point. `onCopy`, `onClose`, `onPrev`, and `onNext` are caller handlers.

## Public Exports and Props

Exports include `PixelProbe`, `PixelProbeProps`, `PixelProbeLabels`, `PixelField`, and `PixelFieldType`. Key props are `fields`, `count`, `index`, `labels`, `onCopy`, `onClose`, `onPrev`, `onNext`, and `className`.

## Controlled State

The panel has no internal query state. The demo keeps current pixel index and closed state outside the block, then updates status text from copy, close, previous, and next callbacks. Real apps usually re-fetch pixel data in `onNext` and `onPrev`.

## Accessibility

Copy and close buttons use `labels.copy` and `labels.close`. Prev / next buttons use Tooltip for readable descriptions. Field values are selectable text; units and lock markers should be supplementary and not replace field names.
