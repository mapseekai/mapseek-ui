# ResourceSidebar

ResourceSidebar is the resource-library left rail for resource type, categories, counts, rename, and remove entry points.

## Installation

<RegistryInstall registryName="resource-sidebar" />

## Import

```tsx
import {
  ResourceSidebar,
  type ResourceSidebarCategory,
  type ResourceSidebarLabels,
  type ResourceSidebarProps,
  type ResourceTab,
} from "@/registry/blocks/resource-sidebar"
```

## Usage

Drive the rail with controlled `tab` and `activeCat`, passing categories and the allItems label for the current tab.

## Public Exports and Props

Exports include `ResourceSidebar`, `ResourceSidebarCategory`, `ResourceSidebarLabels`, `ResourceSidebarProps`, and `ResourceTab`.

## Loading, Empty, Error, and Status

Tab, category selection, and category actions are caller-controlled. The demo covers type switching, category selection, create, rename, and remove states.

## Accessibility

Types and categories are buttons; rename and remove actions expose names through Tooltip/title.
