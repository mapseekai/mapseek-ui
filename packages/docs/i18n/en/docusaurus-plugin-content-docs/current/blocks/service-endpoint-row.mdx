# ServiceEndpointRow

ServiceEndpointRow displays one GET endpoint, highlights URL template parameters, and provides copy/open actions.

## Installation

<RegistryInstall registryName="service-endpoint-row" />

## Import

```tsx
import { ServiceEndpointRow, type ServiceEndpointRowProps } from "@/registry/blocks/service-endpoint-row"
```

## Usage

Pass title, subtitle, URL, icon, and callbacks. When real tokens or auth are required, disable open and explain it with a tooltip.

## Public Exports and Props

Exports include `ServiceEndpointRow` and `ServiceEndpointRowProps`. Key props are `title`, `subtitle`, `method`, `url`, `copyLabel`, `onCopy`, `openDisabled`, `openTooltip`, and `onOpen`.

## Loading, Empty, Error, and Status

The block does not touch clipboard or windows directly; copy, open, disabled, and error messaging are controlled by callbacks and props.

## Accessibility

Copy and open buttons must provide `copyLabel` and `openLabel`. The URL is rendered in a code area with horizontal scrolling.
