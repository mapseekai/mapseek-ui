# StorageMeter

StorageMeter is a local storage usage chip with an expanded breakdown for OPFS, IndexedDB, Caches, and related buckets.

## Usage

Shape `navigator.storage.estimate()` or backend quota results as `StorageMeterData`, then pass labels, refresh callback, and optional footer.

## Public Exports and Props

Exports include `StorageMeter`, `formatBytes`, `StorageMeterData`, `StorageMeterLabels`, and props. Key props are `data`, `loading`, `error`, `errorLabel`, `onRefresh`, and `footer`.

## Loading, Empty, Error, and Status

Supports normal, near-limit, unsupported, loading refresh, and error messaging. The demo covers normal, high-watermark, and unsupported data.

## Accessibility

The trigger aria-label includes used storage, quota, and percentage; the unsupported branch explains the reason through a tooltip.
