# StyleEditorPanel

StyleEditorPanel provides the header, scroll content, section, card, and empty-state parts for a style-editing side panel.

```tsx
} from "@/registry/blocks/style-editor-panel"
```

## Usage

Use `StyleEditorPanelRoot` for the panel boundary, `StyleEditorPanelHeader` for title and actions, `StyleEditorPanelContent` for scrolling, and product cards inside `StyleEditorPanelSection`.

## Public Exports and Props

Exports include root, header, content, section, card, empty components, and their props. The block owns layout and structure only, not source state.

## Loading, Empty, Error, and Status

Use `StyleEditorPanelEmpty` for empty sections. Loading and error states should be switched by the caller inside each section; business state such as add and remove stays outside the block.

## Accessibility

Titles, remove buttons, and add buttons need clear text or `aria-label`. Keep the scroll region keyboard reachable, and do not rely on icon-only card actions without names.
