# StyleFunctionEditor

StyleFunctionEditor provides the panel, stops table, action area, and icon button parts for style-function editing.

## Installation

<RegistryInstall registryName="style-function-editor" />

## Import

```tsx
import {
  StyleFunctionPanel,
  StyleFunctionStopsTable,
  type StyleFunctionStopsTableProps,
} from "@/registry/blocks/style-function-editor"
```

## Usage

Callers provide concrete inputs and stop data. `StyleFunctionPanel` fixes the container, `StyleFunctionStopsTable` fixes table structure, and `StyleFunctionActions` hosts save or conversion actions.

## Public Exports and Props

Exports include `StyleFunctionPanel`, `StyleFunctionStopsTable`, `StyleFunctionActions`, `StyleFunctionIconButton`, table column types, and props.

## Loading, Empty, Error, and Status

The block does not parse expressions or validate stops. Render row-level errors in the wrapper, and replace the table body for loading or empty states.

## Accessibility

Tables need a caption and column headers. Icon buttons must receive `aria-label`; tooltips are supplemental only.
