# Collapsible

Collapsible is a lightweight single-section disclosure container. It is suited to dataset details, optional settings, and supporting notes, while Accordion is better for a list of related sections.

## Exports

`Collapsible`, `CollapsibleTrigger`, and `CollapsibleContent` map to Radix Collapsible root, trigger, and content.

## States and Behavior

Use `open/onOpenChange` when external button text and business state need to stay synchronized. `CollapsibleTrigger asChild` lets you reuse existing Button styling.

## Accessibility

The trigger should describe what it expands. If expanded content contains critical state, keep a summary near the trigger so users do not need to open it to understand the current state.
