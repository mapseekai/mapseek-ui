# Command

Command powers command palettes, local action search, and empty search results. It is based on cmdk and reuses Mapseek input-group, grouping, separator, and shortcut styles.

## Installation

<RegistryInstall registryName="command" />

## Import

```tsx
import { Command, CommandInput, CommandItem, CommandList } from "@/registry/ui/command"
```

## Exports

`command.tsx` exports `Command`, `CommandDialog`, `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup`, `CommandSeparator`, `CommandItem`, and `CommandShortcut`.

## States

`CommandInput` drives cmdk filtering; `CommandEmpty` renders when no result remains. `CommandItem disabled` marks unavailable actions, and checked items show the built-in check icon.

## Accessibility

Command text should describe the result, not just the verb. With `CommandDialog`, make sure the trigger has an accessible name and Escape returns focus to that trigger.
