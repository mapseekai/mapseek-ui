# Field

Field composes label, description, error, and control layout so form spacing, error state, and responsive direction remain consistent.

## Installation

<RegistryInstall registryName="field" />

## Import

```tsx
import { Field, FieldDescription, FieldError, FieldLabel } from "@/registry/ui/field"
```

## Exports

`field.tsx` exports `FieldSet`, `FieldLegend`, `FieldGroup`, `Field`, `FieldContent`, `FieldLabel`, `FieldTitle`, `FieldDescription`, `FieldSeparator`, and `FieldError`.

## States

`orientation` supports `vertical`, `horizontal`, and `responsive`. Invalid fields use `data-invalid="true"` together with control-level `aria-invalid`; disabled fields can use field-level `data-disabled` to affect labels.

## Accessibility

`FieldError` uses `role="alert"`. Labels should point to real controls; error text should explain the format, impact, and recovery path.
