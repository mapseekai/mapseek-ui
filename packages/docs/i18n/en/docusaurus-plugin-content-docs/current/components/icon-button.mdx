# IconButton

IconButton is for icon-only tool actions such as edit, download, refresh, and delete. It stays square and uses `danger` for destructive actions.

## Exports

`icon-button.tsx` exports `IconButton`. The component inherits native `button` props and adds `size="sm" | "md"` and `danger`.

## States

Default buttons use muted hover styles; `danger` uses destructive foreground and a tinted background. `disabled` removes pointer interaction and lowers opacity.

## Accessibility

Every icon button needs `aria-label`; add `title` or an outer tooltip when the meaning is not obvious. Destructive actions still need confirmation or undo at the workflow layer.
