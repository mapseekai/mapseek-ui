# InputGroup

InputGroup combines inputs, textareas, icons, units, and inline buttons inside one boundary. Use it for search, coordinates, unit values, and multiline notes.

## Exports

`input-group.tsx` exports `InputGroup`, `InputGroupAddon`, `InputGroupButton`, `InputGroupInput`, `InputGroupText`, and `InputGroupTextarea`.

## States

Addons support `inline-start`, `inline-end`, `block-start`, and `block-end`. Child `aria-invalid` styles the group boundary; disabled children lower the whole group state.

## Accessibility

Addons do not replace labels. Search, coordinate, and notes fields still need a visible label or `aria-label`; unit text should not be the only error signal.
