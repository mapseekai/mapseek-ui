# Label

Label gives form controls a clickable, readable name. It uses compact monospace typography and responds to peer or group disabled states.

## Installation

<RegistryInstall registryName="label" />

## Import

```tsx

```

## Exports

`label.tsx` exports `Label`. The component inherits native `label` props; `htmlFor` is the most common one.

## States

Use `htmlFor` to bind a control id. Required markers belong to content; disabled controls can affect label styling through peer or field group state.

## Accessibility

Label text should name the input's meaning, not its type. Required, error, and help states should be readable text, not color or symbols alone.
