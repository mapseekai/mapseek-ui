# Popover

Popover renders actionable or readable floating content such as layer metadata, local settings, and short contextual details.

## Installation

<RegistryInstall registryName="popover" />

## Import

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/registry/ui/popover"
```

## Usage

<ComponentDemo title="Contextual floating content" description="Covers basic content, side, alignment, and controlled close while keeping portal content inside the viewport." source={overviewSource} minHeight={440}>
  <PopoverOverviewDemo />
</ComponentDemo>

## Exports

`popover.tsx` exports `Popover`, `PopoverTrigger`, `PopoverContent`, `PopoverHeader`, `PopoverTitle`, and `PopoverDescription`.

## States

Uncontrolled mode lets the trigger manage open state; controlled mode uses `open/onOpenChange`. Use `side`, `align`, and offsets for placement.

## Accessibility

Triggers need clear names. Put actionable content in Popover rather than Tooltip; Escape close should return focus to the trigger.
