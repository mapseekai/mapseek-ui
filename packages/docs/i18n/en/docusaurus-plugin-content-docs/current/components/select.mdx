# Select

Select is a finite single-value picker for CRS, formats, and modes. It is built on Base UI Select and maps item labels back into the trigger value.

## Exports

`select.tsx` exports `Select` and exposes options through `Select.Item`. The root supports `value/onValueChange`, `defaultValue`, `placeholder`, `disabled`, and `size`.

## States

Use `value/onValueChange` for controlled state and `defaultValue` for static defaults. `size="sm"` provides a 28px trigger; `disabled` prevents opening the list.

## Accessibility

Selects without visible labels need `aria-label`. Keyboard users should be able to open with Enter/Space, move with arrow keys, choose with Enter, and close with Escape.
