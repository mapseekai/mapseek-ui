# Separator

Separator is a lightweight divider for toolbars, metadata, menu groups, and visual regions inside panels.

<RegistryInstall registryName="separator" />

## Exports

`Separator` inherits Base UI Separator props and renders horizontally by default. `orientation="vertical"` switches to vertical sizing and self-stretch behavior.

## States and Behavior

Separator has no interaction state. It communicates visual grouping and should not replace headings, labels, or accessible structure.

## Accessibility

Keep separator semantics when a semantic split is useful; decorative separators should never receive keyboard focus. Do not use a divider as the only information hierarchy.
