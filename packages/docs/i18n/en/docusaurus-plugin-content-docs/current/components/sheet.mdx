# Sheet

Sheet handles long content, detail views, and local tasks while preserving page context through side or bottom panels.

## Installation

<RegistryInstall registryName="sheet" />

## Import

```tsx
import {
  Sheet,
  SheetBody,
  SheetContent,
  SheetTrigger,
} from "@/registry/ui/sheet"
```

## Exports

`sheet.tsx` exports `Sheet`, `SheetTrigger`, `SheetContent`, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetBody`, `SheetFooter`, and `SheetClose`.

## States

`side` supports `top`, `bottom`, `left`, and `right`. Set width, height, and scroll boundaries for long content so the main page is not pushed out of the viewport.

## Accessibility

Every Sheet needs a title and readable close button. Escape and backdrop close should return focus to the trigger; long forms should keep footer actions visible.
