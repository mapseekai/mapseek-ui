# Slider

Slider handles continuous or stepped values such as layer opacity, thresholds, and style strength. It keeps Base UI keyboard and pointer dragging behavior.

## Installation

<RegistryInstall registryName="slider" />

## Import

```tsx
import { Slider } from "@/registry/ui/slider"
```

## Exports

`slider.tsx` exports `Slider`. The component inherits Base UI Slider root props, including `value/onValueChange`, `defaultValue`, `min`, `max`, `step`, and `disabled`.

## States

Controlled sliders use array values; a common single-thumb shape is `[50]`. Disabled lowers control opacity and prevents thumb interaction.

## Accessibility

Provide `aria-label` or a visible label. Keyboard users can use arrows, Home/End, or Page keys to change values; the page should show the current value or unit.
