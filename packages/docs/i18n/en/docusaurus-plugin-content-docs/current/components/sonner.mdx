# Sonner

Sonner provides Mapseek-styled toast notifications with square corners, hairline borders, type icons, and top-center placement.

## Installation

<RegistryInstall registryName="sonner" />

## Import

```tsx
import { Toaster, toast } from "@/registry/ui/sonner"
```

## Usage

<ComponentDemo title="Toast types" description="Covers success, error, warning, info, default, description, and action using the page root Toaster." source={overviewSource} minHeight={300}>

</ComponentDemo>

## Exports

`sonner.tsx` exports `Toaster` and the `toast` helper from `sonner`. Render `Toaster` once near the app root, then trigger notifications with `toast.*`.

## States

Use `toast.success`, `toast.error`, `toast.warning`, `toast.info`, or `toast` for message type. Add `description`, `action`, and `cancel` when needed.

## Accessibility

Use toast for short-lived results or background status, not as the only durable state. Errors and recoverable actions should also remain visible near the triggering surface.
