# Switch

Switch represents immediate on/off settings such as cache, visibility, and sync state. Its rounded track and thumb are an intentional exception to Mapseek's square control rule.

## Installation

<RegistryInstall registryName="switch" />

## Import

```tsx
import { Switch } from "@/registry/ui/switch"
```

## Usage

<ComponentDemo title="Switch states" description="Covers sm/default sizes, checked/unchecked, disabled checked, invalid, and controlled state." source={overviewSource} minHeight={340}>

</ComponentDemo>

## Exports

`switch.tsx` exports `Switch`. The component inherits Base UI Switch root props and adds `size="sm" | "default"`.

## States

Use `checked/onCheckedChange` to control the switch, or `defaultChecked` for initial state. `disabled` marks it unavailable; `aria-invalid` marks an invalid setting.

## Accessibility

Switch needs an accessible name. Use it for immediate toggles, not form choices that require a Save action; those are usually better as Checkbox.
