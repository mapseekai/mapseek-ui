# Toggle

Toggle is a single pressable on/off button for formatting, snapping, display modes, and local switches. It keeps Base UI Toggle `aria-pressed` semantics.

## Exports

`toggle.tsx` exports `Toggle` and `toggleVariants`. The component supports `pressed/onPressedChange`, `defaultPressed`, `disabled`, `aria-invalid`, `variant`, and `size`.

## States

Controlled state uses `pressed/onPressedChange`; static initial state uses `defaultPressed`. Pressed state is expressed with `aria-pressed` and `data-state=on`.

## Accessibility

Toggle text should name the switched property, such as Bold or Snap. Icon-only toggles need `aria-label` and a readable pressed state.
