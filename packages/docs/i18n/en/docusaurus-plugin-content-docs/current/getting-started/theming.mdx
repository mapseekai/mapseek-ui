# Theming

Mapseek UI base tokens come from `@mapseek/theme`. After installation, theme CSS lives in application source and is consumed by the application's Tailwind and shadcn setup.

## Install the Theme

```bash
bunx shadcn@4.8.0 add @mapseek/theme
```

`@mapseek/theme` provides the colors, radii, shadows, and state tokens used by Mapseek UI components. It is not a remote stylesheet; installed theme files belong to the application source tree.

## src/app.css

Import shadcn, Tailwind, and the Mapseek theme output from the application's `src/app.css`. A typical entry looks like this:

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "./theme.css";
```

If your project already has `src/app.css`, merge the Mapseek theme import into that entry and preserve application-owned token overrides and `@source` rules.

## Ownership Boundary

The application owns `src/app.css` and installed theme files. Mapseek UI provides initial tokens and component conventions; brand color, dark mode, typography, density, and business status colors should be reviewed and committed at the application layer.
