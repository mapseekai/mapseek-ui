# Mapseek UI

Mapseek UI is a shadcn source component set for maps, spatial data, and operational interfaces. Installation copies components into your application source tree so teams can review, adapt, and maintain them over time.

## Installation Model

Use shadcn to install component source into your project instead of consuming Mapseek UI as a runtime component package. Component source, style tokens, and dependency declarations come from this repository's registry output.

```bash
bun run registry:build
```

## Bilingual Docs

Chinese is the default site without a path prefix. English is published at `/en` and keeps the same structural metadata so later component pages can be checked for localization parity.
